# 城影记 · 电脑端可点击原型

阶段 4 的页面与流程原型，用于审阅地图选城市、年份影集框、添加照片、整理顺序和文字记录等交互。它没有账户、上传或持久存储后端，不是已完成的正式产品。

## 本机打开

使用项目现有的 Node.js，无需安装依赖。在项目根目录运行：

```powershell
& 'D:\SDK\Node\node.exe' .\prototype\travel-journal\server.mjs
```

终端会显示本机预览网址。在 Edge 中打开这个完整网址，保留其中的随机路径。服务默认使用随机空闲端口；需要固定端口时可在命令末尾添加 `--port 4173`。服务只监听 `127.0.0.1`，按 `Ctrl+C` 关闭。每次启动的随机路径不同，请使用当次输出的网址。

原型默认以“旅人”演示账号打开；退出后可体验注册和登录。用户名可自行填写，口令固定为 `demo2026` 并设为只读，不接受真实密码。这仅用于演示页面流程，不能当作真正的账户和身份认证。演示数据只存在于当前浏览器页面内存中；刷新、关闭或重新打开页面后会重置，也不会同步到其他电脑。

## 地图与照片

新版首页以中国地图为主体，使用 SVG 绘制，支持缩放、拖动和直接选择城市。空影集不点亮；当前账号加入第一张照片后，城市标记及其实际行政区域才着色。无照片城市以入口点呈现，并非所有城市都预先绘制行政分界线。

天地图国家目录本次未提供国家轮廓，背景通过 34 份省级边界同色呈现，并按最新反馈显示细省界线，缩放时线宽保持稳定；影集仍按城市进入。所有行政查询共用串行队列，请求开始间隔至少 1.5 秒，逐步显示进度和轮廓；失败后手动重试仅补齐缺失部分。首次完整显示约需一分钟，当前页面内复用结果，刷新会重新加载。当前取得 380 个城市及同级/特殊行政单位入口，不能将该数量等同于内地地级市数量。数据来源与特殊地区约定见 [来源说明](assets/china-cities-source.md)。

2026-09-21 的必要检查：34 份背景全部成功、无缺失；城市点击、缩放返回、空账号及空影集不点亮、首次加图后对应城市区域点亮通过；原图实测为 4608 × 3456，浏览器错误与警告为空。详见 [本次检查记录](../../docs/page-flow.md#新版地图关键检查2026-09-21)。随后已补齐 [实际 Edge 关键复查](../../docs/edge-review-2026-09-21.md)，包括新版地图、城市范围点击、年份、原图、文字与前后排序。本轮不代表地图所有版图要素或正式上线条件已验收。

服务运行时读取此前地图验证使用的 `validation/map-probe/.env.local` 中的 `TIANDITU_KEY`，也可使用当前进程的同名环境变量。密钥不写入网页源文件、README 或日志，只通过当前本机随机路径下的 `./map-config` 提供给浏览器，再用于天地图官方 HTTPS 请求。未配置有效密钥时，此接口返回 `key: null`；地图实际显示还取决于网络、应用权限及配额。地图浏览会产生真实天地图服务调用。

## 服务边界

- 只开放 `GET` / `HEAD`，校验 `Host`、随机路径、请求 `Origin` 与跨站请求标记。
- 只提供当前原型目录中的顶层 HTML/CSS/JS、`assets/` 下允许的静态资源、地图配置和上述六个固定样本路由；不提供目录列表、服务源码、环境文件或项目文档。
- 静态路径经过解码、组件检查与真实路径范围检查；各响应使用 `no-store`。
- CSP 允许本机资源及天地图官方 HTTPS 资源，并升级不安全资源请求。为兼容地图 SDK，保留脚本动态求值与内联样式权限；没有允许任意外部脚本、嵌入框架或表单提交。这是本机原型配置，正式部署时需要按实际功能重新评估。

脚本验证可导入 `createPreviewServer({ port: 0 })`，返回 `{ server, url, origin, basePath, close }`。使用完毕应调用 `await close()`。导入模块不会自行启动监听。

后续正式开发才实现账号隔离、私人原图副本、数据库、持久排序与记录、备份和跨电脑访问；当前原型不证明这些能力已经完成。
