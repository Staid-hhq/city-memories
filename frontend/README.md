# 城影记前端

React 19 + TypeScript + Vite + React Router。命令从本目录执行，依赖由 `package-lock.json` 固定；首次安装使用 `npm ci`，日常运行不重复安装。

## 源码分工

```text
src/
├─ main.tsx                 挂载入口
├─ app/App.tsx              登录、会话与顶层路由
├─ features/
│  ├─ albums/               独立相册库、城市/年份页面及共享业务类型
│  ├─ imports/              单图、批量导入和队列规则
│  ├─ photos/               原图浏览、文字、排序、移动、重复查看
│  ├─ map/                  中国市级地图、几何计算和公共数据加载
│  └─ trash/                回收站、删除确认和恢复
├─ shared/                  HTTP、会话隔离、原图读取和共享操作反馈
└─ styles/global.css        全局及现有功能样式
```

每个文件的具体用途见[文件导航](../docs/file-guide.md)。功能模块使用 `shared/api.ts` 请求服务；城市/影集类型放在 `features/albums/types.ts`，不从页面组件反向导入类型。全局样式仍集中在 `styles/global.css`；V2-01 统一白色背景及导航/相册排版，没有升级依赖或锁文件。

首页“选择一座城市”在搜索词为空时请求 `/cities?view=province-centers&limit=100`，一次展示 34 个省级地区的省会、首府或本身入口，按城市拼音 A–Z 排列，台湾地区为台北。输入城市/所属地区后使用原全国城市搜索及分页，点“返回省会列表”清除搜索并恢复默认；广东默认只有广州，搜索仍可找深圳、东莞等城市。`Journal.tsx` 保留请求取消、失败重试和空结果提示，`albums.spec.ts` 核对默认列表及搜索往返，`home-sidebar.spec.ts` 的异步锚点检查跟随新请求地址。本次扩展后端查询参数，更新需正常停止项目、重建前端、正常启动后再 `Ctrl+F5`；无新迁移或依赖，范围与验证见[省会默认入口记录](../docs/reports/2026-10-25-province-city-entries.md)。

登录后的顶部提供“城市地图”和“我的相册”。当前页面层级为 `/albums` 城市相册库 → `/cities/{id}` 城市相册中的年份影集框 → `/albums/{id}` 年份影集的照片；一个城市只在相册库显示一张卡，不按年份重复。`features/albums/AlbumLibrary.tsx` 读取 `GET /api/v1/me/city-albums`，负责城市卡、筛选分页和返回位置；城市内继续用既有 `/cities/{id}/albums` 读取年份卡。首页“最近整理”保留直达年份影集，旧 `/me/albums` 接口继续服务该入口。

城市相册支持城市/所属地区搜索、本人年份下拉和年份/最近整理排序；搜索显式提交，年份和排序即时应用，可组合使用并清除回默认。年份筛选表示“包含该年份影集的城市”，城市卡片的影集数、有效照片数和封面仍按该城市全部年份计算，不把卡片缩成单个年份。年份选项仍从 `GET /api/v1/me/albums/options` 读取本人的全部年份影集，不受已加载页数或搜索词限制。年份默认以城市最新具体年份倒序、仅未标年份的城市置后；最近整理使用该城市全部年份影集中的最新更新时间。

筛选条件、已加载数量和位置只保存在当前账号的 `Journal` 内存，返回时按这些条件重读本人资料，不持久保存私人相册。切换条件清空旧结果并取消在途请求；失败重试保留条件，筛选无结果与从未创建相册分别提示。退出或换号清除记忆，迟到请求不能带回上一账号或上一条件的内容。接口与当前验证见[相册查找记录](../docs/reports/2026-10-23-album-library-filters.md)。

封面选择沿用照片列表和原图读取，调用 `PATCH /api/v1/albums/{id}/cover`；保留版本核对、失败后显式重读和恢复自动封面入口。具体边界见 [V2-01 记录](../docs/reports/2026-10-21-v2-album-library.md)。

城市卡与年份影集卡均采用 3:4 封面，横竖原图以 `object-fit: cover` 展示；完整城市名允许换行，卡片资料对齐。城市卡显示全市年份影集数与有效照片数，封面取最新有有效照片的年份影集并尊重该影集的手选封面；无照片时显示空封面。进入城市后，各年份独立成框，具体年份倒序、未标年份最后，空年份框仍保留；再进入对应照片页。年份页先返回该城市的年份影集列表，再通过“返回我的相册”回到此前筛选和展开位置；照片页返回入口沿用“返回某城市年份影集”文案。经原图、批量导入和页面刷新，来源标记沿用现有路由规则；完整刷新不承诺恢复先前内存中的条件和页数。裁切不改原图或年份封面偏好，不新增城市封面写入设置。当前实现、接口与验证见[城市相册层级记录](../docs/reports/2026-10-24-city-album-hierarchy.md)，早期排版范围保留在[卡片排版记录](../docs/reports/2026-10-23-album-card-layout.md)。

本次城市相册层级新增只读后端接口，不修改数据库结构、照片归属、依赖或锁文件。已完成 V2-01 升级时，正常停止项目、重建前端、正常启动后再 `Ctrl+F5`，以同时加载接口和页面；不重复迁移或重建已有相册。

V2-04 操作反馈子项使用 `shared/OperationFeedback.tsx` 统一页面内的说明、进行中、成功、警示和失败状态。提示包含标题、具体结果及就近操作，不自动消失；失败使用 `role="alert"`，其余使用 `role="status"`。单张/批量导入区分校验暂存与真正保存，显示保存位置、数量及部分成功；失败保留原参数重试和查询入口。封面区分写入与重读确认，删除/恢复明确当前文件及返回入口，结果未确认时先核对，沿用现有幂等和版本规则。无新后端接口、依赖、锁文件或迁移；已启用相册筛选接口时构建后 `Ctrl+F5` 即可。实际范围与本轮验证见[操作反馈记录](../docs/reports/2026-10-23-operation-feedback.md)。

V2-04 连接提示子项在 `shared/api.ts` 安全解码响应，保留 HTTP 状态和结构化业务错误；非 JSON 的失败响应仍按 401/403/5xx 处理，成功状态但协议不完整时返回 `RESPONSE_INVALID`，不展示原始 HTML。`App.tsx` 进一步校验会话/登录用户字段及登录返回的 CSRF 字符串，不完整登录结果不能进入私人页面；首次会话读取及已登录后的核对最多等待 15 秒，区分服务不可用、连接失败、异常响应和超时。启动等待和失败均可“重新连接”并查看折叠的本机启动步骤；重连取消旧会话请求，不重放业务写入。

已登录后的会话核对失败保留 `Journal`，提供“重新核对登录状态”；同账号成功时清除提示，失效或换号仍清理旧账号资料。退出处理中或退出失败时不因回到窗口等会话检查重新显示旧账号，仍须明确完成退出。未保存内容仅在当前页面内保留，重新核对不等于保存；原图查看层打开时继续遵守现有模态焦点范围，正常关闭查看层后再使用顶层核对按钮。既有窗口可见、多窗口通知仍会核对，没有新增后台轮询或自动重连。纯前端变更，无新接口、依赖或迁移；更新与本轮实际验证见[连接提示记录](../docs/reports/2026-10-23-connection-feedback.md)。

V2-04 手机端细节子项在不超过 760px 的布局中扩大常用按钮/链接至至少 44px 触控高度，文本输入、选择和备注采用 16px 字号，主导航两个入口等宽，复选框沿用整段标签点击。不超过 480px 时相册筛选改为单列，完整显示排序选项。批量重选上下排列、文件输入占满可用宽度，年份工具和队列摘要允许换行；待确认表格保持至少 640px，在名为“待确认原图列表”的可聚焦区域内横滚，并显示操作提示，不撑宽整页。移动照片摘要改为单列，长文件名和说明换行。

原图查看层在手机布局使用动态视口高度（保留 `vh` 回退），顶部关闭按钮保持可见；标题最多显示两行，下方另列完整文件名，短横屏可滚动查看内容。地图触摸默认滑动页面、轻点城市进入相册；粗指针设备通过“移动地图”开启二维拖动，通过“完成移动”恢复滚页，按钮使用 `aria-pressed` 表示模式。鼠标/笔拖动和滚轮缩放保留；加减按钮和搜索定位仍可使用，不新增地图捏合缩放。纯前端变更，无新 API、依赖或迁移；浏览器触控模拟不代替真实 iOS/Android、软键盘或刘海屏验收，更新与实际证据见[手机端细节记录](../docs/reports/2026-10-23-mobile-details.md)。

V2-02/V2-03 将首页改为只绘制中国的市级 SVG 地图。`public/map-data/china-cities.v1.json` 提供全部已审核入口的公共几何，`mapService.ts` 按代码、名称、上级、单位类型关联 `/api/v1/map/cities`；本人照片填色仍读取 `/api/v1/me/atlas`。页面不再请求 `/map/config`、世界瓦片或在线逐市轮廓。`CityMap.tsx` 保留拖动、缩放、键盘、搜索定位与返回视角；路径按固定尺度记忆，移动时只更新变换。数据来源、固定版本及许可见[公共地图说明](public/map-data/NOTICE.md)，可重复生成脚本位于仓库 `scripts/build-china-map-data.py`。本次地图更新不新增迁移、依赖或锁文件变更。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev -- --strictPort` | 本机开发服务器，代理 `/api` 到 8000 |
| `npm run build` | TypeScript 检查并生成 `dist/` |
| `npm run start:local` | 本机 5173 端口运行构建预览，需已有 `dist/` |
| `npm run lint` | ESLint 检查源码、测试与配置 |
| `npm run test:e2e` | 默认四组隔离回归；不启用重量级规模测试 |
| `npm run test:delivery` | 构建后用全新空库验收，并复用连续流程 |
| `npm run test:scale` | 显式运行重量级规模验证，先读[工具说明](../validation/scale/README.md) |

`npm run preview` 是 Vite 通用预览命令；日常优先用固定监听地址/端口的 `start:local`。完整启动、配置和更新见[本地手册](../docs/guides/local-first-release.md)。

## 测试分区

- `tests/e2e/`：业务、地图、独立相册和连续流程；也保留少量纯队列/几何/调度规则测试。`auth.spec.ts` 覆盖账号流程、非 JSON 服务错误/权限失败、异常成功响应、超时/手动重连及会话核对时的草稿和账号边界。`maps.spec.ts` 覆盖静态市界、地图内滚轮缩放、缩放边界光标、触屏滚页/移动模式切换和本人资料联动；`map-live.spec.ts` 现在默认验证随应用提供的真实公共资产，不访问在线地图服务或私有 Key。`library.spec.ts` 覆盖城市相册与多个年份影集层级、分页/逐级返回、空态/失败/换号隔离、跨页封面选择与恢复自动；`library-filters.spec.ts` 覆盖城市/地区与年份组合、城市聚合排序及统计、完整年份选项、筛选分页及返回/错误/请求隔离。`home-sidebar.spec.ts` 覆盖双栏/窄屏、本人统计和最近年份影集、返回首页、错误/空态/换号及刷新联动。默认实际 Edge 无界面运行，PowerShell 设置 `$env:CITY_MEMORIES_EDGE_HEADED = '1'` 可显示窗口。
- `tests/delivery/`：构建资源、深链接、同源代理和端口占用检查；交付配置同时复用 `tests/e2e/journey.spec.ts`。
- `tests/scale/`：400/3000 张、双账号、浏览内存检查；不进入默认测试集合。

筛选测试示例：`npm run test:e2e -- tests/e2e/maps.spec.ts`。默认“既有业务 / 地图 / 连续流程 / 首页与相册”四组各自启动临时数据库/服务，避免共享测试账号触发累计登录限流；不要用一个服务替代全部分组。要求本机 Microsoft Edge、项目 Python 环境和空闲测试端口，不复用用户正在运行的服务。

测试默认使用 5173/8000。日常项目正在运行时，在同一测试终端设置 `$env:CITY_MEMORIES_E2E_FRONTEND_PORT = '5274'`、`$env:CITY_MEMORIES_E2E_BACKEND_PORT = '8174'`，可独立运行默认回归及 `test:delivery`；页面上下文与 Origin 均跟随实际测试地址，不连接用户服务。端口覆盖仅供测试，结束后移除这两个环境变量，不放入日常启动配置。

测试使用合成图片和隔离账号，结果不提交到公共仓库。旧 T13 在线瓦片核验属于历史证据，不能代替新图实际资产、覆盖和交互检查；地图结果见[中国地图记录](../docs/reports/2026-10-22-china-city-map.md)，首页结果见[首页改善记录](../docs/reports/2026-10-23-home-map-sidebar.md)，筛选结果见[相册查找记录](../docs/reports/2026-10-23-album-library-filters.md)，卡片结果见[排版记录](../docs/reports/2026-10-23-album-card-layout.md)，操作结果见[反馈记录](../docs/reports/2026-10-23-operation-feedback.md)，连接结果见[连接提示记录](../docs/reports/2026-10-23-connection-feedback.md)，手机端结果见[手机端细节记录](../docs/reports/2026-10-23-mobile-details.md)，省界结果见[省市边界层级记录](../docs/reports/2026-10-23-province-borders.md)，本次结果见[城市相册层级记录](../docs/reports/2026-10-24-city-album-hierarchy.md)。目录整理后已迁移的旧测试路径见[整理记录](../docs/reports/2026-10-17-repository-organization.md)。
