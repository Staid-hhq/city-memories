## 正式工程快速开始

正式代码与既有原型、验证夹具并列保存：

- `frontend/`：React 19、TypeScript、Vite 与 React Router；开发服务器把 `/api` 代理到本机 FastAPI。
- `backend/`：FastAPI、SQLAlchemy、Alembic 与 pytest；`uv.lock` 固定 Python 依赖。
- `.local-data/`：默认的私有本地运行目录，包含 SQLite、原图和暂存目录；已被 Git 忽略，不属于源码。
- `prototype/`、`validation/`：准备阶段的原型与验证证据，未改成正式产品代码。

首次准备后端，在 `backend` 目录运行：

```powershell
uv sync --locked --python 'D:\SDK\Python\Python3.13\python.exe'
uv run python -m alembic upgrade head
uv run uvicorn city_memories.main:app --reload --host 127.0.0.1 --port 8000 --no-proxy-headers
```

默认无需填写密钥，启动时会在私有数据目录生成认证用随机密钥。需要自定义配置时，将 `backend/.env.example` 复制为**项目根目录**的 `.env`，或设置同名环境变量。`CITY_MEMORIES_DATA_DIR` 可指向其他本地持久目录；不要使用前端静态目录、网盘同步目录或源码提交。后端只运行一个实例，保留 `--no-proxy-headers`，避免信任客户端伪造的来源地址。

另开终端，在 `frontend` 目录运行：

```powershell
npm ci
npm run dev
```

Edge 打开 `http://127.0.0.1:5173`，先注册再登录。用户名为 3–32 位英文字母、数字或下划线，密码为 15–128 个字符，支持空格和中文；没有默认账号或演示密码。登录后可搜索深圳、广州、贺州三个已核对的城市，创建 1–9999 年或“未标年份”影集；相同年份直接进入原影集，空影集持久保留。全国城市地图和照片上传尚未开放。两个终端分别按 `Ctrl+C` 停止，重启后账号和影集仍在。生产构建使用 `npm run build`。

验证命令：`backend` 目录运行 `uv run pytest -q`、`uv run ruff check .`；`frontend` 目录运行 `npm run lint`、`npm run build`、`npm run test:e2e`。Edge 回归使用临时数据库并自行启动/停止测试服务，需要本机 Microsoft Edge 及空闲的 8000、5173 端口，不使用现有私人资料。当前 86 项后端测试、7 组 Edge 流程通过；见 [T02 认证记录](docs/t02-auth-verification.md)、[T03 影集交付记录](docs/t03-albums-verification.md) 和 [首批城市映射](docs/t03-city-mappings.md)。已有 T02 环境也需要先执行上述迁移；本机项目库已升级。
