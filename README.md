## 正式工程快速开始

正式代码与既有原型、验证夹具并列保存：

- `frontend/`：React 19、TypeScript、Vite 与 React Router；开发服务器把 `/api` 代理到本机 FastAPI。
- `backend/`：FastAPI、SQLAlchemy、Alembic 与 pytest；`uv.lock` 固定 Python 依赖。
- `.local-data/`：默认的私有本地运行目录，包含 SQLite、原图和暂存目录；已被 Git 忽略，不属于源码。
- `prototype/`、`validation/`：准备阶段的原型与验证证据，未改成正式产品代码。

首次准备后端，在 `backend` 目录运行：

```powershell
uv sync --locked --python 'D:\SDK\Python\Python3.13\python.exe'
uv run alembic upgrade head
uv run uvicorn city_memories.main:app --reload --host 127.0.0.1 --port 8000
```

需要把私人数据放到其他本地持久目录时，先按 `backend/.env.example` 设置 `CITY_MEMORIES_DATA_DIR`。不要把它放进前端静态目录、网盘同步目录或源码提交。

另开终端，在 `frontend` 目录运行：

```powershell
npm ci
npm run dev
```

Edge 打开 `http://127.0.0.1:5173`。当前基础页会通过开发代理检查后端；账号和私人资料接口从 T02 开始实现。生产构建使用 `npm run build`。
