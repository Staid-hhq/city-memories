# T08 · 跨影集移动及重复照片查看交付记录

日期：2026-09-27。状态：已完成。范围依据 [开发计划 T08](development-plan.md)、[接口契约](data-api-design.md)。本次不实现 T09 删除/回收站，不将完整“查看后选择删除重复照片”流程标为通过。

## 可使用的结果

- 照片卡片、原图查看层与重复页均有移动入口。选择本人的目标城市和已有年份，或先创建新年份/未标年份，再核对并确认移动到末尾；目标年份超过一页可继续加载。
- 移动保留照片 ID、原图原字节、文件名、文字、独立存储副本及原导入收据。照片归属与两影集版本在同一事务中更新，失败全部回滚。移走最后一张保留原空影集，城市统计按剩余有效照片计算。
- 目标已有相同内容也正常移入，只显示重复份数，不自动去重。重复页按内容分组、每次最多读取 24 条照片资料，可逐份查看原图和独立文字，关闭默认全部保留。
- 文字、源影集或目标影集已改变时拒绝旧版本请求。响应丢失或冲突保留选择，先查询照片当前位置；仍在原处时展示最新文字/目标版本后再次明确确认，已在其他影集则提供当前位置入口，不自动重放移动。
- 未保存文字进入移动页沿用 T07 离开保护；退出/换号清空移动和重复页的私人资料，晚到响应不能进入下一账号。

## 接口与实现说明

`POST /api/v1/photos/{id}/move` 请求含 `target_album_id, expected_photo_revision, expected_source_revision, expected_target_revision`；严格字段、正整数版本、16 KiB 实际 JSON 上限、本人资源和 CSRF。读取前取得 SQLite 写锁，检查归属和三项版本。目标位置取最大有效位置加一，源位置允许间隔但相对顺序不变；照片和两个影集 revision 各加一。没有文件复制、重编码、合并或删除。

成功返回照片白名单、源/目标 ID 和新版本、target_duplicate_count。无相同内容时该计数为 0，否则为移入后的该组全部份数。同影集请求返回 SAME_ALBUM；照片、源、目标过期版本分别返回 PHOTO_CHANGED、SOURCE_CHANGED、TARGET_CHANGED，均为 409；越权/不存在/非有效照片为 404。

`GET /api/v1/albums/{id}/duplicates` 返回分组片段及全影集组数/份数，limit 默认 24、最多 100，限制**照片条数而不是组数**。同组可跨页，前端合并连续分组。按组代表照片 UUID、position、id 排序；游标签名绑定本人、影集和版本，不包含完整内容哈希。分组与列表只查询当前影集的 active 照片，授权、版本、总数和结果处于一个读取快照。移动、导入或排序使旧游标返回 409，不能继续拼接旧页。

目标新建沿用 T03 创建接口，新建空影集和移动是两个明确操作，取消移动不会删除已建影集。目标城市包含开放目录与本人的历史城市；停用城市不新建，但已有本人影集可选择。刷新/离开取消客户端等待，不承诺撤销已提交的移动；重新打开旧位置可查询当前归属。移动不生成独立幂等收据，旧版本不能自动重放，原导入的已提交收据继续保留且不会重建移动后的照片。

无新依赖、表或迁移，迁移头仍为 `b61e24f803a7`；API 版本更新为 0.8.0。正式应用、测试/截图与私有运行目录的边界不变。

后端新增覆盖：跨城市移到已有影集末尾、文字/ID/存储键/上传关联不变、原图字节一致、源封面/城市统计、移空及移回、三个版本分别冲突、严格输入、CSRF/体积限制、同影集/越权/回收站拒绝、四路同版本并发仅一项成功。故障注入在照片归属写入时触发，确认已处理的影集更新一同回滚并可重试；原导入 commit 重放仍只返回原收据，不将照片重建或移回。

重复测试用一个含 30 张合成图片的影集，其中 29 张组成两组（27 份与 2 份），一个大组跨页；验证 ID 无漏/无重、不同文件名相同内容归组、同名不同内容不合并、其他影集不混入、白名单与游标不输出哈希、篡改/跨影集游标拒绝以及移动后的版本失效。

7 组 Edge 实测：

1. 跨城创建年份、确认前不移动、确认后原图/文字/ID 不变；返回源和目标数量正确，1024 宽无横向溢出。
2. 移入已有相同内容仍全部保留；两份文字独立，查看或关闭不删除。
3. 创建未标年份后移动响应丢失，查询确认当前位置，仅发出一次移动。
4. 其他客户端实际改变目标顺序和照片文字，分别发生冲突；重新核对后显式确认，保留最新文字。
5. 29 张重复成员跨页、网络失败保留已读项、重试无漏项；真实移动后旧游标拒绝并可明确重新核对。
6. 未保存文字拦截进入移动页；26 个新增目标年份的分页选择可用；取消选择不改变归属。
7. 读取失败不显示“无重复”，移动在途退出清理；另一账号不能访问旧影集分组或原图。
