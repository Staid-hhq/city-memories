# T07 · 文字和影集内排序交付记录

日期：2026-09-26。状态：已完成。范围依据 [开发计划 T07](development-plan.md) 和 [接口契约](data-api-design.md)，不包含 T08 跨影集移动、重复查看或后续回收站。

## 交付结果

- 查看照片时可编辑并显式保存纯文本，最多 2000 个 Unicode 码点，允许空字符串、空白和换行；不执行 HTML，不裁剪、不截断，不修改原图或文件名。
- 影集列表增加“整理顺序”：拖动手柄放到目标照片前，或前移、后移、置顶、置底。前后移动操作完整影集，可跨未加载分页；成功后刷新已加载列表，移出当前窗口可直接查看刚调整的照片。
- 文字只更新照片 revision，纯排序只更新影集 revision；无变化不增加版本。照片 ID、文字和原图对应关系在排序及服务重启后保持。
- 多窗口旧版本写入返回 409。文字草稿保留，读取最新内容后由用户选择采用最新文字，或保留草稿并再次保存；排序保留操作上下文，重新加载后再选择操作，不自动重放旧意图。
- 未保存文字时关闭、切图、Esc、站内返回会询问继续编辑或放弃。硬刷新/关页注册 beforeunload 提醒；同账号切回窗口不卸载编辑器，退出/换号立即清除私人资料并拒绝晚到响应。

## 实现边界

接口为 `PATCH /api/v1/photos/{id}/note` 和 `POST /api/v1/albums/{id}/reorder`，继续使用认证、来源校验、CSRF、no-store 与响应白名单。严格正整数版本、不接受额外字段；文字请求体上限 64 KiB，排序 16 KiB，实际接收字节在 JSON 解析前计数。64 KiB 可容纳 2000 个 JSON 转义的补充平面字符；孤立代理字符拒绝。

SQLite 写事务在读取前取得写锁，再核对本人资源和版本。排序只接受被移动照片及锚点，不接受局部分页覆盖全影集；全体有效位置先写入高于旧最大位置的临时区间，再写最终连续位置，两遍更新和影集版本在同一事务中提交。中途数据库失败全部回滚，不暴露临时顺序。文字与排序不读写原图文件。

前端沿用现有依赖，改用 React Router Data Router 以支持 useBlocker，原有页面地址保持不变。拖动使用 HTML 原生事件并提供按钮操作。核对依据：[React Router useBlocker](https://reactrouter.com/api/hooks/useBlocker)、[MDN 拖动操作](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API/Drag_operations)。未新增依赖、表或迁移，迁移头仍为 `b61e24f803a7`。

后端覆盖：

- 文字精确保留、留空、2000 字符边界、补充平面字符、孤立代理字符、非法类型/版本/额外字段；真实流式字节上限和 CSRF。
- 27 张跨页重排、首张封面、空操作、旧分页失效、全体 ID/顺序、照片文字与版本不变、原字节一致。
- 两账号隔离、错误影集/缺失照片/回收站锚点拒绝；四路同版本文字请求与四路排序请求均只有一项成功，其他返回 409。
- 完成临时位置并进入最终位置写入后注入故障，确认事务回滚、版本不变、随后可安全重试。
- 新应用实例读取同一数据库以及真实进程重启；不是仅依赖浏览器刷新或内存数据。

新增 Edge 流程覆盖：

1. 含 HTML 标记的文字只作为纯文本；空白/换行/emoji、2001 禁用、2000 可保存、清空和刷新。
2. 同账号双窗口真实版本冲突，草稿保留、最新内容比较、明确保留草稿后再次保存；切回窗口不丢稿。
3. 未保存关闭、下一张、Esc、浏览器返回的继续/放弃选择；beforeunload 事件可取消。
4. 文字已在服务端保存但响应丢失，原版本再保存返回冲突，查询并采用服务端结果，不重复覆盖。
5. 第 24 张后移跨过未加载的第 25 张、置顶/置底、实际拖动手柄；27 个 ID、文字、原图不变，封面跟随首张，重载保留，1024 宽无横向溢出。
6. 排序响应丢失及另一个客户端实际改变顺序后的版本冲突：不自动重放，保留上下文并重新核对。
7. 文字保存中另一窗口退出，旧草稿和晚到响应不进入登录页或下一账号。
