# V2-04 子项 · 相册卡片排版

日期：2026-10-23。基线：相册查找与排序 `2911753`。本轮统一相册库与城市年份页的封面、文字及空相册排版。仅交付本子项，V2-04 其余浏览细节、第二版整体验收和 T17 部署仍待安排；当前状态见[开发计划](../planning/development-plan.md)。

## 1. 卡片展示

- 共享卡片的封面保持 3:4，横图、竖图统一按封面框裁切展示。展示裁切不改写原图字节，打开照片仍读取完整原图，也不新增缩略图文件。
- 城市和年份不再在封面内外重复。城市完整名称放在图下首行，允许长名称换行并预留两行位置，下方年份和照片数统一对齐；无年份仍显示“未标年份”。
- 空相册封面明确显示“等待第一张照片”。卡片链接的无障碍名称包含完整城市名、年份和照片数，窄屏文字允许换行，避免横向溢出。
- 相册库与城市年份页使用同一组件；城市/所属地区搜索、年份筛选、年份/最近整理排序、分页及返回位置沿用既有规则。手选、恢复自动及失效回退封面不变。

日常操作见[使用指南](../guides/user-guide.md)，此前筛选接口和返回记忆见[相册查找记录](2026-10-23-album-library-filters.md)。

## 2. 实现与更新

调整前端 `AlbumLibrary.tsx` 的共享卡片及 `global.css` 排版，不新增 API、依赖、锁文件或数据库迁移。相册列表仍通过现有接口读取本人资料，封面仍按需读取原图，不修改账号隔离或持久化规则。

已经启用上一轮筛选接口时，从 `frontend` 执行 `npm run build` 后在页面按 `Ctrl+F5` 即可，无须重启后端。若尚未更新至相册筛选版本，仍须按[前一轮记录](2026-10-23-album-library-filters.md)正常重启项目加载接口；不需要新迁移。
