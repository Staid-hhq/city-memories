# 常用文档优化（2026-11-06）

基线为文件整理提交 `9feced0`，开始时工作区干净。本轮按用户授权优化常用文档的准确性和阅读顺序，保留既有文件路径与历史验收记录，不改变业务实现。

## 修正的问题

- 功能指南仍把旧“添加一张原图”“批量导入原图”当作日常入口；当前代码已统一为“添加照片” → “选择照片” → 核对/确认队列 → 上传 → 明确保存。旧 `?import=` 任务恢复独立说明，照片卡移动/回收明确先打开“⋯”。
- 启动指南与本地手册混入多轮“本次更新”，容易让人每次都安装、迁移或重启。现在按实际变化选择操作，并集中维护首次准备与更新顺序；迁移仍需正常停机、核对实际数据目录及已有资料备份，运行按钮不迁移。
- 本地手册含有其他机器需填写地图 Key、手机适配未交付的旧说法；改为当前静态地图无需 Key，已完成窄屏/触控模拟改进，真实手机验收和公开跨电脑访问仍待安排。
- 项目定位还写正式应用未初始化和暖色第一版风格；改为已实现的本机应用、当前白色灰绿界面及仍未交付的范围。单张照片文字与独立游记正文明确区分。
- 前后端 README 从逐轮实施记录改为当前目录职责、命令、接口/状态规则及维护入口，具体字段留在接口设计，历史结果留在分类报告。
