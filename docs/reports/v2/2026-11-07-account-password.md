# 账号密码规则与输入体验

日期：2026-11-07。基线：`955eed2`。范围为用户确认的密码规则和输入体验，不扩展找回密码、修改密码或第三方登录。

## 行为与边界

- 新注册密码及确认密码均为 8–16 个可见 ASCII 字符，允许英文字母、数字和英文半角符号；禁止中文、空格、emoji、全角及控制字符。
- 前后端按完整密码忽略大小写匹配同一份有限弱密码名单，不强制混合字符种类；实际密码从输入到哈希验证均不删改、转换或截断。该名单属于有限本地拦截，不是完整泄露密码库检测。
- 注册长度、字符、弱密码及确认不一致分别提示；后端只映射固定校验类型，不回显密码、输入、Pydantic 异常或私有路径。
- 登录单独接受 8–128 个 Unicode 码点，兼容原有中文、空格、超过新注册长度的密码和旧规则弱密码；不重置或迁移已有哈希。
- 两个密码输入有独立的显隐按钮，支持键盘、粘贴、自动填充和密码管理器；切换登录/注册后清空密码并恢复隐藏。注册提示使用用户指定文案，登录提示仅为“请输入密码”。
- 保留现有用户名、密码哈希、会话、CSRF、来源校验、频率限制与账号隔离。数据库迁移及依赖未变化。
