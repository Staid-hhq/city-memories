# 登录与注册表单错误提示

日期：2026-11-07。基线：`facac61`。本轮为账号模块步骤 2，仅完善表单错误反馈；保留密码规则和步骤 1 的等待/恢复逻辑，未新增修改密码或手机布局重排。

## 行为

- 首次提交前不提前标记无效字段；提交时收集用户名、密码及确认密码的全部本地错误，按字段顺序聚焦首错。
- 各错误显示在对应输入附近，并用边框与文字共同指示；`aria-invalid` 仅在校验失败后设置，`aria-describedby` 同时保留原帮助及对应错误 ID。参考 [WAI 表单通知](https://www.w3.org/WAI/tutorials/forms/notifications/)与 [ARIA21](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA21)。
- 同时可见多条字段提示，只保留一个错误播报区；不重复渲染可见的全局字段错误。网络、凭据错误及未知结果仍在表单级反馈。
- 首次提交后随编辑重新校验，不抢输入焦点、不删改字符；密码变化会重新计算确认密码自身规则和一致性。显隐按钮不提交或清错。
- 注册接口只有指定状态/错误代码可定位字段。用户名重名、密码分类、确认分类与不一致使用精确白名单；5xx、未知代码、登录凭据错误等不猜字段。
- 编辑对应字段才清除其服务端错误；服务端密码不一致随任一密码框编辑解除，并交给本地校验继续核对。错误清除时移除无效标记和错误描述引用。
