# 认证等待与恢复

日期：2026-11-07。基线：`d43be52`。本轮完成用户指定的账号模块步骤 1；字段错误定位、修改密码与手机页面重排属于后续任务。

## 实现

- 认证请求增加 15 秒整体期限，覆盖 CSRF 准备、fetch 及正文读取；不对照片、上传或其他业务 API 添加统一期限。每个操作结束清除计时器，卸载及换代中止旧操作，迟到结果不能回写。
- 登录/注册的超时、断网、5xx 和非法成功响应进入结果不明状态，不自动重放 POST。密码输入恢复为隐藏显示，用户可操作恢复入口，不持续锁在“请稍候”。
- 登录核对使用新操作期限，先刷新 CSRF 再核对当前身份；只有与原提交用户名匹配才进入。当前无有效会话时恢复登录表单；账号不同或核对失败时不进入旧账号。
- 注册未知只带用户名进入登录页并提示尝试登录；不携带密码、不声称已创建，也不增加公开用户名查询接口。
- 退出初次提交与明确重试前核对当前身份/令牌。退出期间立即隐藏私人内容，未知状态提供只读核对及明确重试；确认已无有效登录态或退出响应成功后才完成。发现账号变化时不退出另一个账号。
- 页面恢复、窗口切换及跨窗口通知不能绕过退出未确认状态；CSRF、服务端会话、限流、既定密码规则及原图资料保持原有协议。后端、数据库、依赖没有变更。
