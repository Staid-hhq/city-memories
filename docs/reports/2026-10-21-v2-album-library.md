# V2-01 · 白色界面与独立相册

实施及复查日期：2026-10-21 至 2026-10-22。基线：第一版维护提交 `928aad7`。本轮实现并验证 V2-01，按可独立交付的步骤推进第二版；中国独立市级填色地图及 T17 部署未完成，正文回忆文章未纳入。当前进度只维护在[开发计划](../planning/development-plan.md)。

## 1. 页面与浏览行为

- 全局改为白色背景，统一导航、文字、按钮、留白及封面卡。顶部“城市地图”与“我的相册”可直接切换；独立 `/albums` 页面只展示本人相册。
- 相册库跨城市按年份倒序排列，“未标年份”置后；默认每页 24 本，可继续加载。城市年份页和独立相册页共用大封面卡，显示城市、年份与有效照片数，沿用按需读取原图，不新增缩略图管线。
- 从独立相册进入年份影集后，“返回我的相册”重读此前展开的列表并恢复位置。返回来源经原图查看、页面刷新和批量导入往返保持；位置和已加载数量仅保存在当前账号的页面内存，退出、换号或刷新不承诺跨会话恢复私人列表。
- 相册或分页加载失败提供重试，保留已成功读取的内容；首次失败不冒充空库。换号时取消旧请求，迟到结果不能显示到新账号。
- 在影集照片区“更换封面”后可从任意已加载分页选择照片，支持“恢复自动封面”。手选偏好持久保存；展示时只接受当前影集内本人有效照片，失效时回退到顺序第一张有效照片，无有效照片时为空。封面不改原图字节、照片 ID、文字或照片顺序。
- 封面写入使用影集 revision；冲突或结果未确认时要求重新读取照片列表核对，不自动重放写入。封面变化后继续读取照片分页时使用最新游标，避免拼接旧版本资料。封面写入及重新读取照片期间禁用查看入口，完成后再以最新版本打开，避免旧上下文产生 409。

## 2. 接口与数据库

| 项目 | 本轮实现 |
| --- | --- |
| `GET /api/v1/me/albums` | 本人跨城市相册；`items, next_cursor`；默认 24、最多 100；年份倒序、null 最后，同年按稳定 ID；签名游标绑定账号 |
| `PATCH /api/v1/albums/{id}/cover` | `{photo_id: null|string, expected_revision: int}`；成功返回 `AlbumView`；仅本人影集及本人同影集有效照片；需会话与 CSRF；版本冲突 `409 / ALBUM_CHANGED` |
| 自动封面 | `photo_id: null` 恢复按顺序取第一张有效照片；失效手选封面在读取时回退；空影集返回空封面 |
| 迁移 `c7e9a162b4d8` | 从 `b61e24f803a7` 增加 `albums.preferred_cover_photo_id` 可空字段；旧行默认 null |
| 依赖 | 未升级包管理器、依赖版本或锁文件 |

实现分布：前端新增 `AlbumLibrary.tsx`，调整 `Journal.tsx`、`PhotoGallery.tsx`、`BatchImport.tsx` 的相册来源导航、统一样式、白色主题元数据和默认回归分组；后端调整相册查询、封面修改、模型、数据库版本门禁和备份兼容，并新增对应迁移与隔离测试。现有城市 UUID、相册归属及原图读取权限保持原规则。

## 3. 使用者首次升级

当前实现没有读取或升级用户真实库。日常使用前，由使用者正常停止已有后端、核对实际私有数据目录并完成独立备份，再从项目 `backend` 目录执行：

```powershell
& .\.venv\Scripts\python.exe -m alembic upgrade head
if ($LASTEXITCODE -ne 0) { throw '升级未完成，不要启动新版服务' }
```

迁移成功后从 `frontend` 目录运行 `npm run build`，或在 PyCharm 使用“城影记－前端构建”，然后按原入口正常启动。**PyCharm 的“城影记－启动”不会自动运行 Alembic。** 不通过删库、覆盖配置或重建私人数据来处理缺字段；完整步骤见[本地手册](../guides/local-first-release.md#3-新机器首次准备或更新后)与[软件启动说明](../guides/ide-startup.md)。

备份格式仍为 v1。工具能创建、校验和恢复旧头 `b61e24f803a7` 与新头 `c7e9a162b4d8` 的快照，保持来源 schema，不自动迁移原库、备份或恢复结果。旧备份恢复到全新目录后，需显式指向该恢复目录、升级后再启动新版应用；禁止直接在备份目录迁移或运行服务。新 schema 的封面偏好随备份保留，旧 schema 升级后默认自动封面。见[备份恢复说明](../guides/backup-restore.md#3-恢复到全新目录并检查)。

## 5. 中国市级地图与后续范围

用户明确的目标是：只显示中国、按每个市的区域划分，有本人有效照片的城市填色，点击进入城市相册，并可放大选择小城市。本轮没有把讨论原型直接替换为正式地图，也没有改造或读取私人地图配置。

现有天地图实现仍可用于选城和本人照片点亮，但其按需取得已点亮城市边界的方式，不等于具备完整全国市级灰色背景。V2-02 需先核对来源、使用方式、各市边界与现有业务 ID 的对应，以及台湾市县和重要岛屿/界线覆盖；V2-03 再接入并实际验收。不能只删掉世界瓦片后宣称新地图完成。

2026-10-21 的公开资料初查确认，[阿里云 DataV GeoAtlas 官方说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)仍标明数据“仅供学习和交流使用”，没有据此获得正式应用打包全国市界的明确使用依据；讨论原型的数据还缺台湾市县拆分。自然资源部标准地图和现有天地图官方路径仍作为下一步核验方向，本轮未确认可直接使用的全国市级生产数据集，没有购买或批量抓取地图服务内容。
