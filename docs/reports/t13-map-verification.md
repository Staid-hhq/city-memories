# T13 地图接入真实资料交付记录

日期：2026-10-04。正式实现完成；账号和影集数据走现有后端，地图使用真实天地图服务。验证仅使用临时数据库、合成账号和合成图片，没有打开或迁移用户私人照片，没有发布网站。下一项为 T14 全产品流程回归，不提前宣称 T15 规模或 T17 上线验收通过。

## 实现与数据边界

- 正式业务目录：392 条审核记录，391 条启用、草湖市 1 条待映射；详情见 [目录审核](../reference/t13-city-catalog.md)。原三城 UUID 不变，启动只补缺不覆盖停用记录；没有新增表、迁移或依赖。
- 地图来源：官方 HTTPS WMTS `vec_w` 矢量底图 + `cva_w` 中文注记；遵循 [官方地图服务说明](http://lbs.tianditu.gov.cn/server/MapService.html)。不加载 T12 已发现异常的 `military.js`/SDK，不把 34 省行政面拼接当作全国背景。
- 显示顺序为底图 → 本人城市半透明 SVG → 官方注记 → 城市选择按钮。底图不滤色、不重绘必要界线；暖色只用于页面、入口及本人区域。Web Mercator 与 WMTS 共用投影，SVG 保留全部多面/洞/离岛，填充采用 `evenodd`。
- 主图配独立南海附图，附图同样来自官方服务；可切全国、南海和钓鱼岛相关区域。全国入口用密集分组选择列表，不需要先选省；地图上的普通地名不全部变成影集入口。支持拖动、滚轮、按钮和键盘，进入城市后返回保留同账号内存视角，退出后清空。
- 点亮只读取本人 `/me/atlas` 的有效照片统计。空影集不亮，最后一张移走/删除即熄灭，恢复或正式提交导入后重算。同窗口变更事件、跨窗口 BroadcastChannel 以及窗口重新可见时刷新；广播只含变更信号，不传照片或账号资料。统计读取失败先清除旧点亮并提示核对中，不冒充 0 张。
- 地图配置或外网失败不阻塞独立的城市搜索、本人已保存城市及影集。目录、瓦片、区域分别提示错误和手动重试，不自动无限重试。8 秒未完成的图层提示可继续搜索；行政请求有 25 秒超时。

## 加载预算和缓存

每个地图服务实例单路行政请求，相邻开始至少 1500 ms，最多 20 个等待任务；只为当前视野内本人有照片的前 20 个城市查询边界，放大/平移可继续。全国目录一次查询，不在后台拉取 34 省几何。边界只缓存于当前账号会话内存，最多 64 份；重新进入首页可复用目录和边界。退出、离开和切换目标会取消不再需要的工作。

瓦片只请求可见范围，单视口每层最多 80 片，无全国下载或后台预取。拖动期间只移动已有画面，结束后请求新视野。刷新页面重新核对目录；未配置地图时无地图外网请求。目录中心及边界不保存至数据库、localStorage 或公开构建。

### 多轮加载结果

计时终点：主图 + 南海附图瓦片完成、城市位置核对完成、合成账号的一座深圳照片区域绘制完成；不等待全国所有城市几何。单位毫秒。

| 场景 | 5 次原始值 | 中位数 | 最小–最大 |
| --- | --- | ---: | --- |
| 刷新页面，禁用浏览器 HTTP 缓存 | 1843、2056、2554、2021、1784 | 2021 | 1784–2554 |

这是本机当次网络的 5 个样本，不计算有误导性的长期 p95，不承诺其他网络速度；未清空系统 DNS/TLS/网络缓存。相比旧的 34 请求串行调度，已移除 51 秒的固定排队下限，而不是把旧流程的全部几何“加速下载”。

最终布局复测观测 6 次目录请求、6 次边界请求、542 次瓦片 request 事件，包含刷新、返回和视角检查；这不是供应商控制台扣减/计费证据，也不是一次进入首页的瓦片数。实际日额度仍以账号控制台为准。最终证据保存在 Git 忽略的 `validation/map-plan/results/t13-final-live/`，中间轮次另行保留；只在文档摘录非敏感汇总，不上传响应和截图。最后修正首页样式优先级后，8 项地图离线检查、真实地图流程及 lint/build 均再次通过。

## 本地配置与复现

现有本机 Key 文件已通过根目录 `.env` 的 `CITY_MEMORIES_MAP_KEY_FILE` 引用，无需重新提供 Key 或购买服务。`.env` 和原 Key 文件都被 Git 忽略，不将真实值写入前端源码/构建。其他机器参照 [配置示例](../../backend/.env.example) 设置自己的密钥环境或私有文件，并填写官方当前来源的审图信息及核对日期。缺任一必要配置时退化为文字入口。

审图号码和日期由运行时配置提供，不作为永久前端常量；本次沿用 T12 官方服务显示的 `GS (2026) 4921号`，核对日期 2026-10-04。这是底图来源信息，不表示叠加应用自身已通过地图审查。

认证的同源 `GET /api/v1/map/config` 返回浏览器绘图所需 Key，响应 `private, no-store`；未登录拒绝，错误不回显密钥或文件路径。**浏览器端 Key 必然可被已登录用户在开发者工具看到**，这与“密钥不上传公开仓库”不同；正式部署仍须配置供应商域名限制并复核授权，不宣称浏览器 Key 是服务端保密凭据。没有服务器瓦片代理、共享私人缓存或服务端下载全国几何。
