# V2-04 子项 · 手机端细节

日期：2026-10-23。基线：连接与启动提示 `ef62b92`。本轮改善窄屏控件、批量列表、原图查看层和地图触摸操作，仅交付手机端细节子项。V2-04 整体验收、第二版整体验收及 T17 部署仍待安排；当前进度见[开发计划](../planning/development-plan.md)。

## 1. 问题与结果

此前部分常用按钮较小，手机文字输入字号偏小；批量重选、年份工具和移动照片摘要在窄屏容易挤占空间。原图查看层沿用桌面视口高度，长文件名占据较多标题空间，短横屏的关闭入口和后续操作可达性需要改善。地图原先拦截所有指针拖动，手机滑动地图区域会移动地图，影响整页滚动。

本轮在不超过 760px 的布局中扩大常用按钮和链接至至少 44px 触控高度，文本输入、选择和备注使用 16px 字号，顶部两个主导航入口等宽，复选框沿用整个标签可点。不超过 480px 时相册筛选改为单列，完整显示排序选项。批量重选说明和文件入口上下排列、入口宽度占满可用空间；年份工具和队列摘要允许换行。移动照片摘要采用单列，长文件名和说明自然换行。

待确认表格在手机保留至少 640px 列宽，放在名为“待确认原图列表”的可聚焦区域内横向滚动；页面显示查看后续列的提示，不通过撑宽整页来容纳表格。文件年份、顺序、移除及队列保存规则不变。

手机原图查看层使用动态视口高度并保留 `vh` 回退，顶部关闭按钮保持可见。标题最多显示两行，下方另列完整文件名；短横屏可滚动查看照片资料、备注及操作。前后浏览、原图读取、未保存文字离开提醒和模态焦点规则沿用现有行为。

地图触摸默认用于滑动页面，轻点城市仍进入相册；粗指针设备可点“移动地图”开启二维拖动，再点“完成移动”恢复滚页，按钮用 `aria-pressed` 表示模式。鼠标/笔直接拖动和滚轮缩放保持原规则；加减按钮和城市搜索定位可继续使用，不新增地图双指捏合缩放。

使用方法见[功能指南](../guides/user-guide.md)。

## 2. 实现与更新

修改现有前端样式以及批量导入、原图查看和地图页面的少量标记/触控处理，保留主要桌面布局、现有 API、数据归属、幂等提交、版本核对、账号隔离与返回行为。无新 API、依赖、锁文件或数据库迁移，不读取或升级用户真实数据库，不替用户启动或停止日常服务。

已完成 V2-01 升级且已重启启用相册筛选/年份选项接口时，从 `frontend` 执行 `npm run build` 后在页面按 `Ctrl+F5` 即可，无须重启后端。此前尚未启用筛选接口时，仍按[相册查找记录](2026-10-23-album-library-filters.md)正常重启项目加载接口，不需要重复迁移。

额外窄屏连续流程首次临时配置使用 `.ts`，因配置目录按 CommonJS 解析而不能使用 `import.meta`，测试未启动；改用 `.mts` 后上述 1/1 通过。这是一次性测试配置修正，不是产品失败，也未新增正式项目配置。

视觉复查使用 5275 端口和纯合成浏览器资料，不启动后端或数据库，预览进程已关闭；截图及临时配置仅留本机。正式回归、构建交付和额外连续流程使用独立测试服务、临时数据库、合成账号和图片，测试端口 5274/8174，避开日常 5173/8000，不读取私人配置、账号、原图或日志。

## 4. 交付边界

本轮窄屏与触控证据来自桌面浏览器的视口和触控模拟，不能代替真实 iOS/Android、系统文件选择器、软键盘弹出或刘海屏的实机验收。输入字号及动态视口调整不承诺所有浏览器行为一致；没有新增手机原生应用、离线缓存或地图多指缩放。

日常启动仍只监听本机，手机布局不等于已开放手机跨电脑访问；HTTPS、域名、公开部署及访问方式仍属于 T17。GitHub 仅同步源码与文档，不发布网站或备份私人资料。
