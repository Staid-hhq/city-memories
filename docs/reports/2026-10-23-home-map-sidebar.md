# V2-04 子项 · 首页双栏与滚动改善

日期：2026-10-23。基线：中国市级地图提交 `f94f724`。本轮处理地图占用过高、滚页时误缩放的问题，并增加本人足迹与最近相册。V2-04 其余浏览细节、第二版整体验收和 T17 部署仍待安排，进度以[开发计划](../planning/development-plan.md)为准。

## 1. 页面与交互

- 首页左侧地图画布桌面高 420px，右侧 320px 展示“我的足迹”“最近整理”和相册/选城快捷入口；1100px 及以下改为上下布局，小屏不靠横向滚动查看。
- 普通鼠标滚轮自然滚动页面，指针停在地图上也不触发缩放。加减按钮与键盘缩放、拖动、全国视图、搜索定位、城市点击及同账号返回视角继续保留。
- 足迹仅统计本人已点亮城市、相册和有效照片。最近整理读取 3 本相册，提供有效封面或空封面、城市、年份、照片数，点击进入相册后可返回首页；没有相册时引导选择城市。
- 最近相册和足迹统计响应同页写入、跨窗口通知、窗口聚焦和页面重新可见。加载与失败分别显示，失败可重试，不用零统计或空列表掩盖错误；退出/换号取消在途请求，不接入上一账号的数据。

新增展示组件 [HomeSidebar.tsx](../../frontend/src/features/albums/HomeSidebar.tsx)，请求与刷新仍由 `Journal.tsx` 管理；封面复用按需读取的 `OriginalImage`，不生成缩略图。地图数据、来源许可和市界资产不变，见[此前地图记录](2026-10-22-china-city-map.md)。

## 2. 最近排序接口

`GET /api/v1/me/albums` 新增可选 `sort=year|recent`：默认仍是年份倒序、未标年份最后，原年份游标 scope 保持不变；`recent` 按 `updated_at DESC, id ASC` 排列，游标签名绑定当前账号和排序。首页只取 `sort=recent&limit=3`，独立“我的相册”继续使用年份排序。

最近整理时间复用相册 `updated_at`：创建、导入、移动、排序、回收/恢复及封面改变会更新；仅编辑照片文字不更新相册时间。它不表示所有字段最后一次编辑的时间，也不增加私人资料缓存。接口延续本人资源授权、分页数量限制和签名校验。

本轮无数据库迁移、依赖或锁文件变更。已完成 V2-01 数据库升级的使用者重建前端后，正常停止并重新启动整个项目，再用 `Ctrl+F5` 刷新页面，让后端加载最近排序接口；日常服务正在运行时不要同时启动第二份实例。首次升级仍按[本地更新说明](../guides/local-first-release.md#3-新机器首次准备或更新后)操作。
