# V2-02/V2-03 · 中国市级足迹地图

日期：2026-10-22。基线：V2-01 提交 `a188bba`。本轮完成全国市级数据核对和正式页面替换：只绘制中国、逐市灰色背景、本人有效照片填色、点击进入城市相册。V2-04 其余浏览细节和第二版整体验收仍待安排，T17 部署未进行；进度以[开发计划](../planning/development-plan.md)为准。

## 1. 结果与交互

- 首页不再加载世界 WMTS 瓦片、国外注记或数字聚合标记。391 个已审核城市及同级目的地均有区域，四个直辖市、港澳、省直辖单位和台湾 20 个市县入口沿用原业务 UUID；草湖市保持原待映射状态，不自动新增入口。
- 灰色表示尚未点亮，本人有有效照片的城市填色。空影集不点亮；移动、删除末张和恢复会按本人统计刷新。统计未知时提示核对，不假报零照片；换号和退出取消在途请求，不带入上一账号的私人状态。
- 支持悬停查看城市与照片数、点击或 Enter 进入城市、拖动、滚轮/按钮缩放、方向键移动、全国自适应、名称定位与返回视角。可从城市区域起拖，超过移动阈值时不会误进相册。南海诸岛使用同一源几何与界线显示在附图。
- SVG 路径按固定尺度记忆，拖动缩放只改变变换，不在每次移动时重新计算全部顶点。重新核对会清公共数据缓存后重读；错误或部分匹配保留文字城市入口，并给出明确提示。

## 2. 公共数据与覆盖

正式资产为 [china-cities.v1.json](../../frontend/public/map-data/china-cities.v1.json)，5,082,103 字节，SHA256 为 `eab81b1ea1610b61f7f5615022c5afa99c5a049d947ecf42b82650607d43f1c7`。完整来源说明与许可证随资产分发，见 [NOTICE](../../frontend/public/map-data/NOTICE.md)及 [LICENSES](../../frontend/public/map-data/LICENSES.txt)。

| 内容 | 固定来源与处理 |
| --- | --- |
| 371 个既有城市及同级入口 | GeoCode-Release 固定提交 `6e3534f7af3675b19bd3c5d54c94022959dccdd2` 的公开市界快照；上游声明天地图来源、仓库采用 MIT |
| 台湾 20 个既有市县入口 | `taiwan-atlas@2021.9.20` 的 `counties-10t.json`；MIT 转换项目注明原始政府开放资料条目 7442 与政府资料开放授权第 1 版；不把固定包当作当前条目最新边界 |
| 背景 | 三个没有业务入口的甘肃保护区，以及金门、连江县；不新增相册目的地，台湾整省粗轮廓由市县几何替换 |
| 国界、海岸和南海界线 | 同一 GeoCode 固定提交的公共 GPKG，读取 EPSG:4326 的 `border/coast/ninedash` 线图层，共 542 条原线；不将开放线段闭合成国家面，不造新界线 |

保留多面、离岛和洞；台湾共享弧按 TopoJSON 解码，字形只用于对应既有名称，不用来源县市代码推算天地图代码。坐标量化到小数点后 5 位，极小轮廓保留源精度，不通过抽点删除岛屿。市界按代码、名称、上级和单位类型与当前目录逐项关联；重复编码、非法坐标或格式直接拒绝，名称/归属不一致不绑定到其他城市。公共几何不包含账号、照片、文字或填色统计。

生成脚本 [build-china-map-data.py](../../scripts/build-china-map-data.py) 只用 Python 标准库，固定下载 URL 和 SHA256，核对 391 项覆盖后才写出资产。原始下载及转换缓存留在忽略的 `validation/map-plan/results/map-sources/`，不会被 Playwright 的输出清理删除。它不读取应用 `.env`、私人数据或密钥。数据是固定公开快照，不宣称实时更新或项目已通过官方地图审查。

## 3. 实现与使用更新

正式页面复用 `/api/v1/map/cities` 和 `/api/v1/me/atlas`，通过同源静态路径读取公共几何，不请求 `/map/config`、外部瓦片或逐市行政轮廓，也不需要地图 Key。第一版行政请求兼容方法和后端配置接口仍保留，历史 T13 结果不作为新图验收。

本轮没有修改后端业务接口或模型，不新增依赖、锁文件变更或数据库迁移。已完成 V2-01 的 `c7e9a162b4d8` 升级时，只需在 `frontend` 运行 `npm run build`，或在 PyCharm 使用“城影记－前端构建”，成功后刷新。不要为换地图重复初始化数据库。日常服务已经运行时不再启动第二份实例；完整说明见[启动指南](../guides/ide-startup.md)。

测试增加可选 `CITY_MEMORIES_E2E_FRONTEND_PORT` 和 `CITY_MEMORIES_E2E_BACKEND_PORT`，默认仍是 5173/8000；本轮用 5274/8174 启动临时库服务，避开用户正在运行的实例。测试浏览器上下文和 Origin 跟随实际测试地址，防止另开的上下文误连日常服务。旧 `map-live.spec.ts` 改为默认本地实际资产验证，测试启动器不再读取旧在线地图 Key。
