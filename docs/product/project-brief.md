# 此间集 · 项目定位

更新：2026-11-06。本页说明当前定位和范围，具体规则见[需求与验收](requirements.md)，已完成与待安排任务以[开发计划](../planning/development-plan.md)为准。

## 为谁解决什么问题

此间集（Cijianji）以中国地图和城市相册为入口，帮助个人把原图、单张照片的文字和旅行回忆放在一起，按城市、年份和自定顺序回看。

初期面向项目发起人和少量朋友，每个人自行注册并管理自己的私人资料。10 人以内是预期使用规模，不代表已完成十人长期并发验收；公共城市目录不表示照片公开。

## 当前产品边界

| 方面 | 当前方向 |
| --- | --- |
| 使用方式 | 本机 Web 应用，Edge 为主要验证浏览器；公开部署与跨电脑访问属于 T17 |
| 内容层级 | 城市相册 → 年份影集 → 照片，支持未标年份与空影集 |
| 城市入口 | 中国市级地图及文字搜索，有本人有效照片才点亮；公共矢量随应用加载，不需要在线地图 Key |
| 照片与文字 | 用户主动选择原图，系统保存独立原字节副本；文字附在单张照片上，不改写源文件 |
| 内容整理 | 批量导入、排序、跨影集移动、封面选择和重复照片查看；重复内容由本人决定是否删除 |
| 删除与保护 | 30 天回收站、到期清理、离线一致备份和全新目录恢复；真实备份介质与策略仍需落实 |
| 界面 | 白色、灰绿和衬线标题，地图与照片为主体，减少重复装饰文字 |
| 设备适配 | 已有窄屏布局和浏览器触控模拟改进；真实移动设备验收及原生手机应用未交付 |

预期照片场景为单账号约 3000 张、常去城市单年份数百张，用于约束验证，不是数量上限或长期容量承诺。系统当前不生成缩略图，图片加载和并发需在保留原图规则下优化。

## 核心使用场景

1. 记录：选择城市和年份，从“添加照片”导入一张或多张原图，明确保存，再排序和写文字。
2. 回看：从地图、城市搜索或“我的相册”找到年份影集，查看原图与记录，沿原层级返回。
3. 整理与保护：移动或查看重复照片，自主决定回收；需要时恢复未到期照片，按独立备份流程保护资料。
4. 后续跨电脑访问：完成 T17 部署与迁移验收后，登录同一账号访问同一份资料；当前本机地址不能直接用于其他设备。

## 未纳入当前交付的功能

公共照片浏览、社交分享、多人共编、QQ 等第三方登录、手机相册自动同步、路线规划、智能识别和独立图文游记正文均未交付；讨论过的灵感不自动成为需求。当前文字功能是单张照片备注。

手机可用布局不等于已提供手机公网访问；备份工具也不等于已经替使用者完成真实备份。新增功能应先明确范围，再更新需求和开发计划。

## 怎样判断值得使用

- 能按城市和年份找到想回顾的照片与文字，按自己的顺序浏览原图。
- 保存并重启后，空影集、原图、文字、顺序和归属仍保持。
- 账号资料隔离，误删可在保留期内恢复，备份校验和恢复能保留原图与关系。
- 在明确样本和设备条件下正常浏览整理；公开访问及长期维护另行验收。
