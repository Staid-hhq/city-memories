## 实施与验收约定

1. 每次完成一个可独立交付的任务或紧密相关任务组；开始前检查 Git，保留已有改动。
2. 实现后按变更风险选择必要验证，区分通过、失败、跳过与未测；失败修正后复查，不把历史结果当成当前通过。
3. 使用隔离账号、临时数据库和合成图片验证；不以真实私人资料做回归。规模和在线服务核验单独安排，不因请求成功就宣称地图完整性或上线条件通过。
4. 保存原始字节，不生成独立小预览图；修改该规则或扩大交付范围先明确需求。
5. 小型维护追加维护日志，独立功能/重要验收写阶段报告；同步任务状态、文件导航并提交推送 GitHub。源码同步不代替数据备份，也不表示发布网站。
