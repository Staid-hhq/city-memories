# 功能使用指南

日常启动、停止和更新见 [本地第一版手册](local-first-release.md)；本页集中说明现有功能和使用边界。

当前相册按“城市相册 → 年份影集 → 照片”组织，一个城市只显示一张相册卡，进入后可查看多个年份影集框。首次从第一版升级时须按[更新步骤](local-first-release.md#3-新机器首次准备或更新后)显式升级数据库；PyCharm 运行按钮不会自动迁移。已完成 V2-01 升级时，城市相册和省会默认入口更新不需要重复迁移或重新建相册；请正常停止项目、重建前端、正常启动，再 `Ctrl+F5` 刷新以加载接口和页面，不必填写地图 Key。

导入、换封面及删除/恢复会在操作区域显示持续的进度、成功、警示或失败提示，说明处理结果和接下来可做的操作，不自动消失。显示结果尚未确认时，按提示查询或重新核对，再决定是否重试。具体改进见[操作反馈记录](../reports/2026-10-23-operation-feedback.md)。

首次打开时会核对登录状态，超过 15 秒显示“连接等待超时”。连接失败、服务暂时不可用或服务响应无法识别时，页面给出对应说明；可展开“查看本机启动步骤”，确认 PyCharm 中“城影记－启动”的前后端均已就绪，再点“重新连接”。等待期间也可重新连接，取消本次等待后重新核对；按钮不会启动服务或重复提交照片操作。

登录后若出现“暂时无法核对登录状态”，当前页面及未保存内容仍在本页，连接恢复后点“重新核对登录状态”。同账号核对成功时提示消失；确认登录过期会回到登录入口，换号仍清除旧账号内容。未保存草稿不持久保留，连接核对也不确认之前的保存结果；请继续按对应操作的查询/核对入口处理。原图查看层打开时，先按已有离开提醒正常关闭查看层，再使用顶层核对按钮。说明见[连接提示记录](../reports/2026-10-23-connection-feedback.md)。

手机布局扩大了常用按钮和表单控件，顶部“城市地图”“我的相册”等宽排列，小屏相册筛选上下排列以显示完整排序选项，长文件名与说明允许换行。批量列表和原图查看层的手机操作见下文；本轮通过浏览器窄屏和触控模拟核对，尚未进行真实 iOS/Android、软键盘或刘海屏验收，也没有开放手机跨电脑访问。具体范围见[手机端细节记录](../reports/2026-10-23-mobile-details.md)。

## 1. 账号、城市相册与年份影集

Edge 打开 `http://127.0.0.1:5173`，先注册再登录。用户名为 3–32 位英文字母、数字或下划线，密码为 15–128 个字符，支持空格和中文；没有默认账号或演示密码。登录后可通过地图或搜索选择 391 个已审核入口，创建 1–9999 年或“未标年份”影集；相同年份直接进入原影集，空影集持久保留。搜索结果按页加载，跨城移动的目标选择也可“加载更多目标城市”。

首页“选择一座城市”默认每个省级地区显示一个入口：省份显示省会、自治区显示首府，直辖市和港澳显示本身，台湾地区显示台北。34 项按城市名称拼音 A–Z 一次显示完，从澳门到郑州；广东默认只显示广州。想选深圳、东莞等其他城市，在搜索框输入城市名或所属地区后点“搜索”；输入“广东”可查该省的已开放城市。点“返回省会列表”恢复默认入口。详情见[省会默认入口记录](../reports/2026-10-25-province-city-entries.md)。

顶部“城市地图”用于选城市，“我的相册”进入只展示本人城市相册的独立页面。比如广州的 2023、2024、2025 年影集会合在一张“广州市”城市卡中；城市卡显示全市年份影集数和有效照片数。点击城市卡进入城市相册，再选择 2023 年、2024 年等年份影集框，最后查看对应照片。已有照片不需要重新导入，相同城市不会按年份重复出现在相册库。

城市卡与年份影集框都使用 3:4 封面，完整名称和统计放在图下，长名称可换行；空影集显示“等待第一张照片”。城市封面取最新有照片年份影集的封面：2025 年为空、2024 年有照片时，会使用 2024 年封面，并尊重该年份的手选封面。城市内的年份框按年份从新到旧排列，“未标年份”最后；空年份框保留，可继续添加照片。横图和竖图按封面框裁切展示，打开后仍是完整原图，不会改写原文件。实际改动见[城市相册层级记录](../reports/2026-10-24-city-album-hierarchy.md)。

可在相册页搜索城市名称或所属地区，输入后提交搜索；例如输入“浙江”可查本人在该地区的城市相册。搜索按文字包含匹配，不需要输入完整名称。年份下拉可选“全部年份”“未标年份”或本人已有的年份；选项来自本人的全部年份影集，不仅是当前显示的 24 个城市。选 2024 年表示只列出包含 2024 年影集的城市，卡片仍显示整座城市的影集总数、照片总数和城市封面；进入后可查看该城市全部年份，不会隐藏其他年份框。

年份、搜索和排序可以一起使用，年份及排序选择后立即生效。默认按城市最新的具体年份倒序排列，只有未标年份的城市放在最后；最近整理按城市内最近一次影集创建、照片导入/移动/排序/回收恢复或封面改变的时间排列，不包括仅修改照片文字。清除筛选恢复全部城市、全部年份和默认排序，点击加载更多继续读取城市卡。

从相册库进入城市，再打开年份影集后，先返回该城市的年份影集列表，再通过“返回我的相册”回到此前筛选、已展开列表和浏览位置。照片页入口仍写作“返回广州市年份影集”等对应城市名称，返回目标就是该城市相册内的年份框。经原图、批量导入往返仍保留来源，首页最近整理仍可直接打开年份影集并返回首页。条件、已展开数量和位置仅在当前账号的页面会话内保留；期间资料变化时按原条件重新读取，完整刷新不承诺恢复此前条件和页数。切换条件清除旧结果，无匹配会提示调整或清除，不冒充从未创建相册；失败可按原条件重试，退出或换号后清除旧账号内容。

在影集照片区点击“更换封面”，再在想选的照片上点击“设为封面”；也可先加载更多照片，从后续分页选择。选择成功后刷新页面仍保留。点击“恢复自动封面”改回按影集顺序选第一张有效照片。手选照片被移走、进入回收站或清除后，封面显示会回退到当前第一张有效照片；没有有效照片时显示空封面。封面选择不改照片顺序、文字或原图。页面会依次说明保存中、写入成功正在刷新及核对后的更新成功；封面更新和重新读取照片期间，查看入口暂时不可用，核对完成后恢复。发生版本冲突或结果未确认时，按提示先重新加载照片列表核对，再明确选择，不自动重复提交。

## 2. 地图

首页左侧显示紧凑地图，右侧“我的足迹”显示本人已点亮城市、年份影集和有效照片数。“最近整理”提供最近 3 本年份影集的封面、城市、年份和照片数，可直接打开后返回首页；下方可进入“我的相册”查看城市卡，或选择城市。最近整理按影集创建、照片导入/移动/排序/回收恢复及封面改变的时间排列，不包括仅修改照片文字。窄屏时足迹栏移到地图下方。资料读取失败会显示重试，不显示假的零统计或空列表。

首页只绘制中国，按 391 个已审核城市及同级目的地划分。还没有照片的区域为灰色，本人有有效照片的城市填色；空影集不会点亮。鼠标移到区域上可看城市名称和照片数，点击区域进入该城市的年份相册。统计读取失败时会显示核对提示，不将未知状态冒充零照片。

省界使用稍深、稍粗的灰绿色线，市界保留为浅色细线；看全国时可辨认省级分隔，放大后继续查看各市，线宽保持稳定。悬停提示包含所属省级地区、城市和本人照片数，便于确认位置。省界只是辅助线，填色和点击仍按城市，不增加整省填色或满屏省名标签。来源及本轮范围见[省市边界层级记录](../reports/2026-10-23-province-borders.md)。

指针在地图内时，滚轮向上放大、向下缩小；移到地图外可正常滚动整页。拖动可移动地图，加减按钮控制缩放，“全国视图”恢复全图。达到最小或最大倍率时，对应按钮变灰，使用普通箭头光标；“－”提示“已是全国视图”表示不能再缩小。小区域可在“定位一座城市”中搜索名称，再点击定位放大或直接打开相册。地图获得焦点后可用方向键移动、加减键缩放；城市区域获得焦点后按 Enter 进入。返回地图保留同账号的视角，南海诸岛在右下附图展示。

触摸地图时，默认上下滑动页面，轻点城市仍可进入相册。需要拖动地图时，先点“移动地图”；完成后点“完成移动”恢复页面滚动。缩放使用加减按钮，或通过城市搜索定位，不提供地图双指捏合缩放。鼠标和笔仍可直接拖动地图，鼠标滚轮规则不变。

地图几何随应用本地加载，不使用世界瓦片、国外标签或在线逐市请求，也不需要地图 Key。加载不完整时可点击“重新核对地图”；下方城市搜索和个人影集入口仍可使用。页面底部“市界数据来源”提供固定数据版本和许可说明；数据不是实时更新的导航底图。地图来源见[中国地图记录](../reports/2026-10-22-china-city-map.md)，本次布局与滚动变更见[首页改善记录](../reports/2026-10-23-home-map-sidebar.md)。

## 3. 单张原图导入

“添加一张原图”区域只选择一张文件。没有选文件时，“上传并校验”会变灰并提示先选图片，鼠标使用普通箭头；按钮不可点不表示正在上传。实际处理时会显示“正在校验文件内容…”或“正在传输并校验原图…”等进度提示。需要一次添加多张，可点按钮旁的“一次上传多张照片”，或影集上方的“批量导入原图”；有未结束的单张导入时，先按本次状态保存、查询或取消。

进入影集后，选择一张 JPEG、PNG 或静态 WebP，点击“上传并校验”，核对城市和年份后再点击“保存到影集”。单张最多 50 MiB、8000 万像素；仅暂存不算保存成功。页面区分上传校验与保存进度，保存成功才显示已保存的归属和数量，并提供查看入口。系统保留原始字节及独立副本，不改写电脑或 U 盘上的源文件。页面地址中的导入标识可用于刷新查询、失败重试和取消；保存结果未确认时按提示查询或以原参数重试，未传完的文件需重选，不承诺断点续传。

## 4. 批量导入与重试

在批量页点击“选择多张原图”，电脑文件窗口内可按住 `Ctrl` 点选多张、用 `Shift` 连选，或 `Ctrl+A` 全选，再确认文件选择。由已有影集进入时，照片仍加入当前城市和年份。

一次添加多张时，在城市页或年份影集点击“批量导入原图”：选文件 → 核对年份与顺序 → 确认队列 → 上传 → 逐批保存。`24-1.jpg` 可识别为 2024 年第 1 张；城市入口按核对后的年份分组，未知年份需指定或选“未标年份”，已有影集入口不自动改变归属。每批最多 400 张，超过自动拆批，同影集按顺序保存；上传最多两路，100% 传输不代表已保存。提示分别说明上传完成、待保存和保存结果，各批成功后可核对城市/年份及保存数量；部分成功会警示未保存项，不能当作整批已完成。失败可逐项重试，部分保存必须明确点击“先保存成功项，放弃其余项”。保存响应不明时先查询或使用同一批次的相同参数重试，不另开队列重复导入。刷新只恢复服务端已登记的批次，未登记文件需重新开始，未传完的原图可批量重选；停止传输后先查询，再重试或取消。过期批次仍可在队列中核对或取消，后台会回收其未保存副本；已保存照片和导入收据不受影响。传输超过 15 分钟租约会释放接收名额，重试需重选文件。

手机核对文件时，在提示下的“待确认原图列表”内左右滑动查看年份、顺序和操作列，整页保持原宽度；键盘也可先聚焦列表再横向滚动。重选原图的文件入口位于说明下方，年份工具和队列摘要会自动换行，保存、取消和重试规则不变。

## 5. 原图浏览

照片列表每次读取 24 条资料，点击“加载更多照片”继续。照片和年份封面直接按需读取原图，不生成缩略图；远离视野的图片卸载。点开照片后可用前后按钮或左右方向键跨页浏览，Esc/关闭/浏览器返回回到本次打开时的列表位置；刷新查看页仍可重开当前照片。影集被其他窗口更新时，按提示重新核对，不混用旧分页。刚保存的照片可从“查看刚保存的照片”直接打开。

手机查看层可上下滚动，顶部保留关闭入口；长文件名在标题最多显示两行，并在图片下方完整列出。短横屏也可滚动到照片资料、备注和操作按钮，关闭或切图仍遵守未保存文字的离开提醒。

## 6. 照片文字

查看照片时可填写最多 2000 个 Unicode 字符的纯文本，点击“保存文字”；可留空，不改原图。未保存就关闭、切图或返回时可选择继续编辑或放弃，刷新/关页使用浏览器离开提醒，强制结束进程不保证保留草稿。多窗口冲突时保留草稿，读取最新文字后明确选择采用最新内容，或保留草稿并再次保存。同账号切回窗口不会清空草稿；退出或换账号仍立即清除私人内容。

## 7. 影集内排序

在影集点击“整理顺序”，可拖动手柄放到目标照片前，或使用前移、后移、置顶、置底；前后移动作用于完整影集，可跨过尚未加载的分页。保存后刷新已加载列表，移到未加载位置可点“查看刚调整的照片”。遇到版本冲突或网络结果不明，先重新加载核对，不自动重放排序。文字与顺序始终跟随照片 ID，重启仍保留。

## 8. 跨影集移动

在照片卡片或查看层点击“移动到其他影集”：选择本人目标城市与年份，没有则先创建，再核对并确认移动到末尾。创建空影集不等于移动，取消时空影集仍保留。移动不复制或改写原图，原 ID、文件名和文字不变；移走最后一张也保留原空影集。成功后可留在原影集或打开目标；冲突或响应丢失先“核对照片当前位置和版本”，不会自动重放。

## 9. 重复照片查看

影集内的“查看重复照片”只显示本影集内文件内容完全相同的有效照片，按组展示、每次最多读取 24 条照片资料。可逐份查看原图与独立文字，关闭页面默认全部保留；不同文件即使重名也不算重复，相似画面识别不在范围内。可以自行选择一份“移入回收站”，确认前不会删除；同内容的其他份不受影响。

## 10. 回收站与恢复

照片卡片、查看层和重复页均可进入删除确认页。先核对提示中的文件名，确认后从正常影集和统计中移除，保留原图与文字 30×24 小时；空影集不删除。顶栏“回收站”按删除时间展示本人未到期照片、原城市年份与截止时间。点“查看与恢复”可看原图和文字，再明确恢复到删除时所在影集的末尾，原 ID 与字节不变；恢复带来重复也全部保留。删除/恢复期间显示当前动作，成功后通过提示旁的入口回到原影集或回收站。冲突或响应丢失先“核对当前状态”，不会自动重试删除/恢复。到期立即禁止读取和恢复，后台再永久清除该份系统原图副本和照片记录；不触碰电脑或 U 盘的源文件，也不删除其他重复副本。

## 11. 到期清理与故障恢复

T10 默认无需额外准备：升级后下次启动会补做清理，运行期间每轮结束后等待 60 秒再检查；不创建 Windows 计划任务。文件占用、权限或数据库故障会保留待清理状态，解除故障后自动重试。服务停机、积压或失败时不保证准点释放空间。同一私有目录由 `maintenance.lock` 强制只允许一个服务实例，退出或崩溃后自动释放锁；不要手动删除运行中的锁文件。配置与排障边界见 [后端说明](../../backend/README.md#t10-到期清理及故障恢复)。

## 12. 停止服务与独立备份

两个终端分别按 `Ctrl+C` 停止，重启后账号、影集和有效照片的原图、文字、顺序及移动归属仍在；请勿删除或提交 `.local-data/`。本地副本不是独立备份；T11 已提供离线创建、校验和新目录恢复命令，见 [备份与恢复操作说明](backup-restore.md)。先正常停止后端以暂停写入和清理，备份到 Git 工作区外的新目录；真正的备份需选择独立、受保护的介质。恢复不覆盖原数据，旧登录会话失效，回收站仍按原期限处理。此次只用合成资料验收，未为用户真实资料创建备份。生产构建使用 `npm run build`。
