# 功能使用指南

日常启动、停止和更新见 [本地第一版手册](local-first-release.md)；本页集中说明现有功能和使用边界。

V2-01 提供白色界面和独立相册入口。首次从第一版升级时须按[更新步骤](local-first-release.md#3-新机器首次准备或更新后)显式升级数据库、重建前端；PyCharm 运行按钮不会自动迁移。已完成 V2-01 升级后，本次首页双栏更新只需构建前端、正常停止并重新启动项目后刷新页面，让后端加载最近排序接口，不必重复迁移或填写地图 Key。

## 1. 账号与城市影集

Edge 打开 `http://127.0.0.1:5173`，先注册再登录。用户名为 3–32 位英文字母、数字或下划线，密码为 15–128 个字符，支持空格和中文；没有默认账号或演示密码。登录后可通过地图或搜索选择 391 个已审核入口，创建 1–9999 年或“未标年份”影集；相同年份直接进入原影集，空影集持久保留。城市列表按页加载，跨城移动的目标选择也可“加载更多目标城市”。

顶部“城市地图”用于选城市，“我的相册”进入只展示本人相册的独立页面。相册以大封面卡片展示城市、年份和照片数，按年份从新到旧排列，“未标年份”放在最后；点击“加载更多相册”继续。进入相册后，通过“返回我的相册”可回到此前已展开的列表和浏览位置；经原图查看、页面刷新或批量导入往返，返回入口仍指向相册库。已展开数量和位置仅在当前账号的页面会话内保留，期间资料有变化时以重新读取的本人资料为准。加载失败会提供重试，不将错误显示为空相册；退出或换账号后不保留上一账号的内容。

在影集照片区点击“更换封面”，再在想选的照片上点击“设为封面”；也可先加载更多照片，从后续分页选择。选择成功后刷新页面仍保留。点击“恢复自动封面”改回按影集顺序选第一张有效照片。手选照片被移走、进入回收站或清除后，封面显示会回退到当前第一张有效照片；没有有效照片时显示空封面。封面选择不改照片顺序、文字或原图。封面更新和重新读取照片期间，查看入口暂时不可用，核对完成后恢复。发生版本冲突或结果未确认时，先重新加载照片列表核对，再明确选择，不自动重复提交。

## 2. 地图

首页左侧显示紧凑地图，右侧“我的足迹”显示本人已点亮城市、相册和有效照片数。“最近整理”提供最近 3 本相册的封面、城市、年份和照片数，打开后可返回首页；下方可直接进入“我的相册”或选择城市。最近整理按相册创建、照片导入/移动/排序/回收恢复及封面改变的时间排列，不包括仅修改照片文字。窄屏时足迹栏移到地图下方。资料读取失败会显示重试，不显示假的零统计或空列表。

首页只绘制中国，按 391 个已审核城市及同级目的地划分。还没有照片的区域为灰色，本人有有效照片的城市填色；空影集不会点亮。鼠标移到区域上可看城市名称和照片数，点击区域进入该城市的年份相册。统计读取失败时会显示核对提示，不将未知状态冒充零照片。

指针在地图内时，滚轮向上放大、向下缩小；移到地图外可正常滚动整页。拖动可移动地图，加减按钮控制缩放，“全国视图”恢复全图。达到最小或最大倍率时，对应按钮变灰，使用普通箭头光标；“－”提示“已是全国视图”表示不能再缩小。小区域可在“定位一座城市”中搜索名称，再点击定位放大或直接打开相册。地图获得焦点后可用方向键移动、加减键缩放；城市区域获得焦点后按 Enter 进入。返回地图保留同账号的视角，南海诸岛在右下附图展示。

地图几何随应用本地加载，不使用世界瓦片、国外标签或在线逐市请求，也不需要地图 Key。加载不完整时可点击“重新核对地图”；下方城市搜索和个人影集入口仍可使用。页面底部“市界数据来源”提供固定数据版本和许可说明；数据不是实时更新的导航底图。地图来源见[中国地图记录](../reports/2026-10-22-china-city-map.md)，本次布局与滚动变更见[首页改善记录](../reports/2026-10-23-home-map-sidebar.md)。

## 3. 单张原图导入

进入影集后，选择一张 JPEG、PNG 或静态 WebP，点击“上传并校验”，核对城市和年份后再点击“保存到影集”。单张最多 50 MiB、8000 万像素；仅暂存不算保存成功。系统保留原始字节及独立副本，不改写电脑或 U 盘上的源文件。页面地址中的导入标识可用于刷新查询、失败重试和取消；未传完的文件需重选，不承诺断点续传。

## 4. 批量导入与重试

一次添加多张时，在城市页或年份影集点击“批量导入原图”：选文件 → 核对年份与顺序 → 确认队列 → 上传 → 逐批保存。`24-1.jpg` 可识别为 2024 年第 1 张；城市入口按核对后的年份分组，未知年份需指定或选“未标年份”，已有影集入口不自动改变归属。每批最多 400 张，超过自动拆批，同影集按顺序保存；上传最多两路，100% 传输不代表已保存。失败可逐项重试，部分保存必须明确点击“先保存成功项，放弃其余项”。刷新只恢复服务端已登记的批次，未登记文件需重新开始，未传完的原图可批量重选；停止传输后先查询，再重试或取消。过期批次仍可在队列中核对或取消，后台会回收其未保存副本；已保存照片和导入收据不受影响。传输超过 15 分钟租约会释放接收名额，重试需重选文件。

## 5. 原图浏览

照片列表每次读取 24 条资料，点击“加载更多照片”继续。照片和年份封面直接按需读取原图，不生成缩略图；远离视野的图片卸载。点开照片后可用前后按钮或左右方向键跨页浏览，Esc/关闭/浏览器返回回到本次打开时的列表位置；刷新查看页仍可重开当前照片。影集被其他窗口更新时，按提示重新核对，不混用旧分页。刚保存的照片可从“查看刚保存的照片”直接打开。

## 6. 照片文字

查看照片时可填写最多 2000 个 Unicode 字符的纯文本，点击“保存文字”；可留空，不改原图。未保存就关闭、切图或返回时可选择继续编辑或放弃，刷新/关页使用浏览器离开提醒，强制结束进程不保证保留草稿。多窗口冲突时保留草稿，读取最新文字后明确选择采用最新内容，或保留草稿并再次保存。同账号切回窗口不会清空草稿；退出或换账号仍立即清除私人内容。

## 7. 影集内排序

在影集点击“整理顺序”，可拖动手柄放到目标照片前，或使用前移、后移、置顶、置底；前后移动作用于完整影集，可跨过尚未加载的分页。保存后刷新已加载列表，移到未加载位置可点“查看刚调整的照片”。遇到版本冲突或网络结果不明，先重新加载核对，不自动重放排序。文字与顺序始终跟随照片 ID，重启仍保留。

## 8. 跨影集移动

在照片卡片或查看层点击“移动到其他影集”：选择本人目标城市与年份，没有则先创建，再核对并确认移动到末尾。创建空影集不等于移动，取消时空影集仍保留。移动不复制或改写原图，原 ID、文件名和文字不变；移走最后一张也保留原空影集。成功后可留在原影集或打开目标；冲突或响应丢失先“核对照片当前位置和版本”，不会自动重放。

## 9. 重复照片查看

影集内的“查看重复照片”只显示本影集内文件内容完全相同的有效照片，按组展示、每次最多读取 24 条照片资料。可逐份查看原图与独立文字，关闭页面默认全部保留；不同文件即使重名也不算重复，相似画面识别不在范围内。可以自行选择一份“移入回收站”，确认前不会删除；同内容的其他份不受影响。

## 10. 回收站与恢复

照片卡片、查看层和重复页均可进入删除确认页。确认后从正常影集和统计中移除，保留原图与文字 30×24 小时；空影集不删除。顶栏“回收站”按删除时间展示本人未到期照片、原城市年份与截止时间。点“查看与恢复”可看原图和文字，再明确恢复到删除时所在影集的末尾，原 ID 与字节不变；恢复带来重复也全部保留。冲突或响应丢失先“核对当前状态”，不会自动重试删除/恢复。到期立即禁止读取和恢复，后台再永久清除该份系统原图副本和照片记录；不触碰电脑或 U 盘的源文件，也不删除其他重复副本。

## 11. 到期清理与故障恢复

T10 默认无需额外准备：升级后下次启动会补做清理，运行期间每轮结束后等待 60 秒再检查；不创建 Windows 计划任务。文件占用、权限或数据库故障会保留待清理状态，解除故障后自动重试。服务停机、积压或失败时不保证准点释放空间。同一私有目录由 `maintenance.lock` 强制只允许一个服务实例，退出或崩溃后自动释放锁；不要手动删除运行中的锁文件。配置与排障边界见 [后端说明](../../backend/README.md#t10-到期清理及故障恢复)。

## 12. 停止服务与独立备份

两个终端分别按 `Ctrl+C` 停止，重启后账号、影集和有效照片的原图、文字、顺序及移动归属仍在；请勿删除或提交 `.local-data/`。本地副本不是独立备份；T11 已提供离线创建、校验和新目录恢复命令，见 [备份与恢复操作说明](backup-restore.md)。先正常停止后端以暂停写入和清理，备份到 Git 工作区外的新目录；真正的备份需选择独立、受保护的介质。恢复不覆盖原数据，旧登录会话失效，回收站仍按原期限处理。此次只用合成资料验收，未为用户真实资料创建备份。生产构建使用 `npm run build`。
