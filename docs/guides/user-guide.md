# 功能使用指南

更新：2026-11-07。本页说明当前网页中的操作；启动、安装和更新见[本地手册](local-first-release.md)，备份命令见[备份指南](backup-restore.md)。

内容按“城市相册 → 年份影集 → 照片”组织。照片导入后保留独立原图副本，文字附在单张照片上；每个账号只管理自己的资料。

## 1. 账号、城市相册与年份影集

在 Edge 打开 `http://127.0.0.1:5173`，先注册再登录。用户名为 3–32 位英文字母、数字或下划线，没有默认账号。新注册密码及确认密码执行当前[密码规则](../architecture/data-api-design.md#3-注册与会话)：8–16 位，仅支持英文字母、数字和英文半角符号，不支持中文、空格、emoji、全角或控制字符，并拦截有限的常见弱密码；不强制同时包含多种字符。两次密码须完全一致，输入不会自动删改。

密码旁的“显示/隐藏”按钮可用鼠标或键盘操作，确认密码有独立按钮；保留粘贴和浏览器密码管理器支持。已有账号仍使用原密码登录，原有中文、空格及超过新注册长度的密码仍可登录；登录接受 8–128 个字符。切换登录与注册会清空密码并恢复隐藏。本轮没有修改或找回密码入口。

首页的“选择一座城市”默认显示 34 个省级地区入口，按城市拼音 A–Z 排列：省会、自治区首府、直辖市和港澳本身，台湾地区使用台北。想选其他城市，输入城市名或所属地区后搜索；点“返回省会列表”恢复默认入口。

“我的相册”每个城市只显示一张卡。点击城市卡 → 选择年份影集 → 查看照片；可创建 1–9999 年或“未标年份”影集，相同年份进入已有影集，空影集仍保留。年份从新到旧，“未标年份”最后。

### 查找和返回

- 搜索支持城市名和所属地区的文字包含匹配，可与年份、排序组合使用。
- 选择某年会筛出包含该年影集的城市，城市卡仍显示该城市所有年份的统计和封面；进入后也能看到其他年份。
- 默认按城市最新具体年份排列；“最近整理”按影集创建、导入、移动、排序、回收/恢复或换封面的时间排列，仅修改照片文字不计入。
- 从照片返回年份列表，再返回相册库，可保留本账号页面会话内的筛选、已展开列表和位置。刷新不保证恢复这些状态，退出或换号会清除。

### 设置封面

在年份影集点“更换封面”，再选照片并点“设为封面”；可加载更多后选择。点“恢复自动封面”改用顺序中的第一张有效照片。手选照片被移走或回收后，展示自动回退；没有有效照片时显示空封面。

城市卡使用最新有照片年份影集的封面，最新年份为空时继续向前查找。卡片会裁切封面以适应版式，打开查看仍是完整原图。换封面不改变照片顺序、文字或原文件；结果不明时先按提示重新核对。

## 2. 地图

地图只绘制中国，覆盖 391 个已审核城市及同级目的地。本人有有效照片的城市填色，空影集不点亮；普通未点亮城市同色无市界，悬停、键盘聚焦或定位时可临时显界。省界及国界/海岸始终保留，直辖市和港澳沿用省级外轮廓。

| 想做什么 | 操作 |
| --- | --- |
| 打开城市相册 | 点击区域，或聚焦城市后按 Enter |
| 定位小城市 | 点入地图上方搜索框，选择香港/澳门/珠海快捷入口，或搜索其他城市；定位后可从城市卡打开相册 |
| 缩放和移动 | 鼠标滚轮在地图内缩放、地图外滚页；鼠标拖动平移，也可使用加减按钮及键盘 |
| 清除定位 | 关闭城市卡，或在地图内按 Esc，保留当前视角 |
| 返回全图 | 点“全国视图”，同时清除定位 |
| 手机上拖动地图 | 先点“移动地图”，结束后点“完成移动”；默认触摸滑动页面，缩放使用加减按钮，不支持双指捏合 |

定位按完整城市范围放大，保留离岛；定位本身不会把零照片城市计为点亮。返回地图保留当前账号的视角。

首页“我的足迹”显示点亮城市、年份影集和有效照片数，“最近整理”可打开最近 3 本年份影集。加载失败会显示重试，不用假零代替未知统计。

地图使用随应用加载的固定公共矢量，不需要地图 Key。正常时从“更多”选择“重新核对地图”；加载失败时提示旁直接提供重试。页面的独立选城与相册入口仍可使用，私人资料仍需后端正常运行。数据版本和许可见[地图资料说明](../../frontend/public/map-data/NOTICE.md)。

## 3. 单张原图导入

一张、多张和拖入照片都使用同一个入口：

1. 进入城市或年份影集，点击“添加照片”。
2. 点“选择照片”或拖入文件；再次选择或拖入会替换待确认列表，此时尚未上传。
3. 核对年份和顺序，点击“确认队列”。
4. 点击“上传队列 / 重试未完成项”，等待校验结果。
5. 对各批明确点击“保存本批全部照片”，以保存结果为准，再打开刚保存的照片核对。

支持 JPEG、PNG、静态 WebP，单张最多 50 MiB、8000 万像素；不支持 HEIC、RAW 或动画，不自动转码。系统不移动或改写电脑/U 盘的源文件。**上传到 100% 或校验通过，都不等于已经保存。**

### 恢复旧导入任务

旧的 `?import=` 链接仍可进入原单张任务，按状态查询、重新选择、保存或取消。该兼容页面中的“上传并校验”“保存到影集”仅用于旧任务；新添加使用上面的统一入口。结果不明时先查询，未传完文件需重选，不承诺断点续传。

## 4. 批量导入与重试

电脑文件窗口可用 `Ctrl` 多选、`Shift` 连选或 `Ctrl+A` 全选。一张和多张的保存步骤相同，批量时还需核对以下规则：

- 从城市入口添加时，按核对后的年份分组；从已有年份影集添加时，全部保留在该影集，不因文件名自动改变归属。
- `24-1.jpg` 可识别为 2024 年第 1 张，两位年份按 2000–2099 理解；未知年份需指定或选择“未标年份”。重名、同编号不会自动合并。
- 每批最多 400 张，超出自动拆批；最多两路上传，同影集按队列顺序保存。
- 上传失败可逐项重试；部分保存需明确选择“先保存成功项，放弃其余项”。保存结果不明先查询，或用原批次、相同参数重试，不另开队列重复导入。
- 保留当前页面地址便于继续查询。刷新只恢复已经登记的批次，未登记项需重新开始，未传完文件需重选并从头传输；停止传输后也先查询状态。
- 未提交批次有到期时间，过期后不能继续上传或保存，可取消清理；15 分钟接收租约不是整个批次的保留期限，已保存照片不受批次取消影响。

手机核对时可在“待确认原图列表”内横向滚动；整页仍保持原宽度。

## 5. 原图浏览

照片列表每次读取 24 条资料，点“加载更多照片”继续。封面和照片按需读取原图，远离视野的图片卸载，不另生成缩略图。

打开照片后，用前后按钮或左右方向键切换；Esc、关闭或浏览器返回可回到本次打开时的位置。其他窗口修改影集后按提示重新核对，避免混用旧分页。

手机查看层可上下滚动，顶部保留关闭入口；长文件名会在资料区完整显示。关闭和切图仍会检查未保存文字。

## 6. 照片文字

查看照片时可填写最多 2000 个 Unicode 字符的纯文本，点“保存文字”；可留空，不改原图。

未保存就关闭、切图或返回时，可继续编辑或明确放弃；刷新/关页使用浏览器离开提醒。草稿不保证跨刷新或强制结束保留。发生多窗口冲突时，先读取最新文字，再明确选择采用最新内容或保留草稿重新保存；退出或换号会清除旧账号内容。

## 7. 影集内排序

在年份影集点“整理顺序”，拖动手柄放到目标照片前，或使用前移、后移、置顶、置底。调整作用于完整影集，可跨过尚未加载的分页；移动到未加载位置时可点“查看刚调整的照片”。

版本冲突或结果不明时先重新加载核对，不自动重放排序。照片 ID、文字和原图保持对应。

## 8. 跨影集移动

照片卡先点“⋯”，再选“移动到其他影集”；原图查看层也有直接入口。选择本人的目标城市与年份，核对后确认移动到末尾；没有目标影集可先创建，取消移动时已创建的空影集仍保留。

移动不复制或改写原图，照片 ID、文件名和文字不变；移走最后一张仍保留原空影集。冲突或响应丢失时先“核对照片当前位置和版本”。

## 9. 重复照片查看

影集内点“查看重复照片”，只检查本影集中文件内容完全相同的有效照片。可逐份查看原图及各自文字，默认全部保留；重名不等于内容重复，也不识别相似画面。

需要删去某份时，明确选择“移入回收站”并确认；其他副本不受影响，不自动去重。

## 10. 回收站与恢复

照片卡通过“⋯”进入“移入回收站”，原图查看层和重复页也有入口。先核对文件名再确认；该份照片从正常影集和统计中移除，保留原图与文字 30×24 小时。

顶栏“回收站”列出本人未到期照片及截止时间。点“查看与恢复”，核对后恢复到删除时所在影集的末尾；照片 ID、原图和文字保持，恢复后即使重复也全部保留。冲突或结果不明先“核对当前状态”。

到期立即禁止查看和恢复，后台再永久清理该份系统副本和记录；不会删除电脑/U 盘的源文件或其他重复副本。

## 11. 到期清理与故障恢复

后端默认在启动时补做清理，运行期间每轮结束等待 60 秒再检查。文件占用、权限或数据库故障会保留待清理状态，解除后自动重试；停机、积压或失败时不保证准点释放空间。

同一数据目录只允许一个服务实例，不手动删除运行中的 `maintenance.lock`。配置和排障见[后端说明](../../backend/README.md#t10-到期清理及故障恢复)；关闭清理不会延长回收站期限。

### 连接或保存遇到问题

首次核对登录状态最多等待 15 秒。失败时展开“查看本机启动步骤”，确认前后端就绪，再点“重新连接”；该按钮不会启动服务或代为保存。

登录、注册和退出也最多等待 15 秒，超时只表示结果尚未确认，不代表服务端没有执行：

- 登录结果不明时点“核对登录状态”。确认是本次账号后进入；当前未登录时可重新提交。核对失败可再次核对，也可明确选择“重新填写并登录”，不会自动重复提交密码。
- 注册结果不明时点“前往登录”，用刚才的用户名和密码尝试登录。页面只预填用户名，不传递密码，也不会将未知结果提示为“账号已创建”。
- 退出结果不明时私人页面继续隐藏。点“核对退出状态”确认当前情况，仍登录时可“重试退出”。若其他窗口切换了账号，先“重新连接并核对账号”，不会直接退出另一个账号。

请先在页面内核对结果；确认退出之前，关闭或刷新页面不能当作退出成功。

登录后的“重新核对登录状态”可在同账号核对成功后继续当前页面，但不能证明先前保存已成功。上传、封面、排序、移动或恢复的结果不明时，使用各自提示中的查询/核对入口，再决定是否重试。账号确认过期或切换账号会清除私人页面；草稿仍需主动保存。

## 12. 停止服务与独立备份

先保存文字与上传结果，再按[启动指南](ide-startup.md#3-停止与下次再开)正常停止前后端。关闭网页不等于停止服务。

回收站、本机副本和 GitHub 均不能代替独立备份。离线工具及操作顺序见[备份指南](backup-restore.md)。已有窄屏和触控模拟改进，真实 iOS/Android、软键盘或刘海屏尚未验收；公开网址、跨电脑访问与原生手机应用也未交付。
