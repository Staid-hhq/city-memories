# 本轮重构文档

本轮先梳理前端，再按需要安排后端。首页已定下「城市地图」「我的相册」「添加照片」三个入口。下一份文档是用户流程与页面原型，用来确认从这三个入口怎样完成任务。

| 阶段 | 文档或记录 | 当前进度 |
| --- | --- | --- |
| 开发前 | 1. [产品需求与验收标准](requirements.md) | 已编写，产品约定和 6 项待执行的前端验收场景可查阅。 |
| 开发前 | 2. 用户流程与页面原型 | 下一项。画出桌面和窄屏的首页，以及浏览、添加和返回的路径。 |
| 开发前 | 3. 技术方案 | 待编写。根据原型说明页面如何拆分、地图何时加载及所需的后端支持。 |
| 开发中 | 4. 开发 README | 实现时核对并更新[项目](../../README.md)、[前端](../../frontend/README.md)和[后端](../../backend/README.md)的原有说明。 |
| 开发中 | 5. 接口契约 | 联调前核对[现行契约](../current/architecture/data-api-design.md)，记录重构所需的接口及兼容要求。 |
| 开发中 | 6. 测试与验收记录 | 实现后记录实测环境、逐项结果和遗留问题。 |
| 发布及上线后 | 7. 部署与运维手册 | 发布前准备，运行后维护。现行本机操作见[使用手册](../current/guides/local-first-release.md)和[备份说明](../current/guides/backup-restore.md)。 |
| 发布及上线后 | 8. 发布说明与变更记录 | 有新版交付时记录改动、已知限制和使用者需要执行的操作。 |

当前应用的使用与维护入口见[现行版本文档](../current/README.md)。全部项目文档见[总索引](../README.md)。
