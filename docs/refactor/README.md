# 本轮重构文档

本轮先梳理前端，再按需要安排后端。首页以「城市地图」为首要入口，另有「我的相册」和「添加照片」。进入独立地图页后可以选城市、看年份和照片。[打开可点击原型](prototype/index.html)或[查看流程和页面预览](user-flows-and-prototype.md)。原型待评审，确认后再编写技术方案。
