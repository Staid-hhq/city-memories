# 文档索引

| 你想做什么 | 从哪里开始 |
| --- | --- |
| 启动、使用或维护目前可运行的版本，查阅现行接口与历史交付 | [现行版本](current/README.md) |
| 设计新版首页，查阅已定需求、下一份文档和后续验收安排 | [本轮重构](refactor/README.md) |

按文件查找源码、测试、配置和文档时，使用[仓库文件导航](file-guide.md)。

## 维护约定

- 重构中的设计和阶段产出统一从[重构索引](refactor/README.md)进入。根目录、前端和后端的开发 README 随代码维护，索引链接对应原文。
- 新版功能完成验收并交付后，同步更新对应的现行指南和接口说明。旧版本的交付记录保留当时的结论。
- 移动或新增文件时同步文件导航与相关链接，在仓库根目录运行 `node scripts/check-repository.mjs`。
