# City Memories 第一版地图方案

选型日期：2026-09-20；状态复查：2026-09-21。阶段 3 的地图选型与证据说明，未完成项归 T12/T13/T17，见 [开发计划](development-plan.md)。

用户确认：在了解高德公开费用及天地图方案后，用户明确决定第一版使用天地图，随后自行完成个人开发者登录与浏览器端应用创建。

**当前选择：天地图作为地图资料与服务来源，城市入口及有照片的区域点亮采用现有 SVG 交互设计。** 首轮 JavaScript API 4.0 底图与六城探针已通过；新版改用行政区划 V2 几何，并通过实际 Edge 的城市范围、缩放和返回检查。正式完整背景、全部城市映射及首次加载仍待解决；原型的省级几何组合不当作官方完整底图。具体证据见 [可行性记录](feasibility.md) 和 [Edge 复查](edge-review-2026-09-21.md)。

依据：[项目定位](project-brief.md)、[第一版需求](requirements.md)、[可行性记录](feasibility.md)。用户明确地图预算优先免费方案或免费额度；最新地图范围、城市层级、点亮规则与主体布局已作为需求记录，具体控件、特殊行政单位映射及呈现方式仍是待评审的设计安排。

## 用户如何使用

主流程保持：`登录 → 中国地图 → 城市 → 年份影集框 → 该年照片 → 单张原图与文字`。

1. 地图聚焦中国，按地级市或同级城市单元提供直接入口；点选城市后进入其年份影集，不要求先进入省份。
2. 城市入口不以已有照片为条件。空城市也可以进入，选择年份创建影集框，再添加照片。
3. 只有当前账号实际有照片的城市点亮；仅创建空影集不点亮，但空城市入口仍可使用。该规则替代此前「空影集也突出显示」的建议。具体颜色与状态提示在原型中审阅，不仅靠颜色区分。
4. 地图旁提供城市名称搜索，选择结果后进入同一城市页面；同名地点显示所属地区帮助区分。这是城市入口搜索，不扩展为照片检索。
5. 全国视图不强行铺满所有城市名称。随缩放调整城市入口与名称的显示密度，保留搜索直接选城；缩放不增加“先选省”的流程。
6. 返回地图时保留此前浏览的位置与缩放。地图服务暂时失败时给出重试入口，仍可通过本系统已经保存的个人城市列表进入影集；这不代表支持离线使用。

首页扩大地图、压缩大标题和大段介绍，提高底图、地名与城市入口的辨识度；暖色旅行手帐的视觉表达服务于地图和回忆内容，具体效果待原型评审。地图承担选城市及显示已有照片城市的作用；年份仍从新到旧排列，照片仍按本人保存的顺序展示，原图与文字规则不变。

## 地图与城市资料

- 正式地图继续采用天地图官方数据与地图服务，保留适用的来源、标识和审图信息。当前阶段 4 原型使用行政区划 V2 几何绘制 SVG：国家查询未返回轮廓，因此用 34 份省级几何同色显示为背景，显示细省界线，影集仍按城市进入；这不是官方完整底图，也不证明国家版图要素齐备。对外展示前继续核对官方底图呈现与使用条件。来源说明见 [原型数据说明](../prototype/travel-journal/assets/china-cities-source.md) 与 [天地图版权声明](https://www.tianditu.gov.cn/about/copyright)。
- 在底图上呈现地级市或同级城市单元，并建立可点击入口与本系统城市影集的关联。城市区域、名称与辅助标记的具体呈现需结合实际行政数据及原型审阅；底图上的普通文字不自动等于可点击的影集入口。
- 城市信息以官方 [行政区划 V2](http://lbs.tianditu.gov.cn/server/administrative2.html) 为来源。2026-09-21 的原型已在线读取名称、编码、中心坐标和层级，筛选呈现 380 个城市及同级/特殊单位入口；不能据此宣称有 380 个内地地级市。城市实际边界仅在有照片时按需读取，不打包完整地级边界数据集，不混用其他厂商坐标与城市表。
- 第一版以地级市或同级城市单元为主要目的地。直辖市、香港、澳门、台湾地区及其他特殊行政单位的归并和细分尚未逐项确认，需依据实际行政数据形成映射建议；此前直辖市按整座城市、香港和澳门分别设入口的安排作为建议保留，不视为用户已确认的最终口径。地级同等单位、省直辖县级单位等也列入城市清单核查，不以“只保留 city 层级”简单过滤数据，不把覆盖提前写成已通过。
- 城市清单的目标不限于用户已有照片的城市。深圳、广州、香港、澳门、贺州用于首轮样例验证，不能据此限制最终可选城市。
- 本系统使用自己的稳定城市标识关联私人影集，地图平台的行政编码与坐标作为映射资料；平台调整编码不应使影集丢失归属。已定结构见 [数据与接口设计](data-api-design.md)。

## 选择天地图的理由与费用边界

产品第一版默认联网，地图只需显示与选城，不需要路线规划、导航或精确定位。天地图官方 JavaScript API 4.0 指南说明服务免费对外开放，使用前需要申请应用 Key；Marker 文档提供点击事件，可以据此关联本项目的城市页面。当前个人开发者配额适合先开展接入验证。这里确定的是供应商和使用方向，没有购买服务或承诺永久零成本。来源：[官方入门指导](http://lbs.tianditu.gov.cn/api/js4.0/guide.html)、[Marker 文档](http://lbs.tianditu.gov.cn/api/js4.0/pages-class/Marker.html)。文档链接本次通过官方 HTTP 页面读取；应用接入仍使用官方支持的 HTTPS 服务。

2026-09-20 核查国家服务中心公开页面及其页面脚本，当日列出的个人开发者配额如下。本轮文档整理没有重新查询账号权益或条款，上线前须再次核对：

| 服务 | 个人开发者每日调用额度 |
| --- | --- |
| 矢量底图 | 10,000 次 |
| 矢量注记 | 10,000 次 |
| 行政区划服务 | 3,000 次 |
| 地图搜索 | 3,000 次 |

来源：[天地图国家服务中心配额说明](https://cloudcenter.tianditu.gov.cn/center/development/quotaDesc)。公开说明还规定：超出当日配额后拒绝服务，次日恢复；禁止通过爬取、下载等行为批量取得服务内容。[开发者认证说明](https://cloudcenter.tianditu.gov.cn/center/development/developerAuth) 列出的个人开发者范围包含个人及对调用量要求不高的团体。

**上述单位是服务调用，不是用户人数、照片张数或地图打开次数。** 一次地图显示、移动或缩放可能产生多个底图与注记请求。不能用 10,000 次推导能支持 10,000 个用户；实际消耗需在接入后观察控制台。

预算执行方式：先核对并使用账号可获得的基础额度，不开通付费服务。公开配额本身不构成对所有用途永久免费或可任意转售地图数据的承诺。用户已自行注册并创建“城影记”浏览器端应用，行业类别为旅游，域名白名单在本地验证阶段暂留空。后续上线前限制正式域名，并核对当时的 [天地图服务条款](https://www.tianditu.gov.cn/about/service) 与账号权益；若增加收费或广告经营，再核对用途条件。当前未购买服务；测试发生了少量真实官方地图请求，未读取控制台实际用量或账单，不能把请求数等同于已确认计费金额。

不选择高德作为当前首选：其现行服务协议将自然人免费额度限定在个人研究、学习用途，其他用途需要联系办理许可；“免费给别人使用”不能自动套用该范围。来源：[高德服务协议](https://lbs.amap.com/pages/terms/)。

不采用下载 DataV GeoAtlas 数据直接打包的方案：其官方说明限制为学习交流，不能将可下载等同于本项目对外使用已获授权。来源：[DataV GeoAtlas 说明](https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/)。

## 已完成接入与后续配置

1. 已完成：项目所有者创建浏览器端应用并配置本地验证所需 Key；普通影集用户不需要各自申请地图密钥。
2. 按实际控制台要求配置开发地址与上线域名的访问限制。[我的应用](https://cloudcenter.tianditu.gov.cn/center/development/myApp) 提供浏览器端域名白名单说明；本地开发地址的白名单限制尚未验证，当前暂留空。网页地图密钥会随页面请求出现，不能把它当作只有服务器能看到的秘密；其他服务凭据按技术方案分别管理，不提交真实凭据到项目文档。
3. 已完成：独立六城探针，以及新版目录、34 份背景与实际城市范围交互检查；历史结果不重复执行来充当新工作。
4. 尚需：完整映射、密集城市操作、首屏速度和异常网络恢复，以及控制台用量核对；当前 Edge 通过范围见单独复查记录。
5. 后续对外开放前复核账号适用条件、域名配置、完整城市清单与实际访问量，再决定是否仍能在基础额度内运行。

私人影集、照片、备注和账号信息由本系统管理，不作为业务数据提交给地图服务；城市标记只使用公开地名和代表点。本方案不调用照片定位或用户精确位置。网页地图本身会向服务商发出联网请求，不能表述为使用第三方地图时完全没有外部请求。
