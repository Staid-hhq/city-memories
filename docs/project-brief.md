# 城影记 · 项目定位

更新：2026-09-21。阶段 1 已形成工作基线。七阶段进度与入口统一见 [项目总览](../README.md)，功能规则以 [需求文档](requirements.md) 为准。

## 为谁解决什么问题

城影记（City Memories）是一个以中国地图为入口的私人旅行影集网站。使用者选择去过的城市、进入对应年份，按自己安排的照片顺序回顾旅行，并给单张照片留下文字记录。

初期供项目发起人和朋友使用，10 人以内。每个人自行注册账号、维护自己的影集，只能浏览自己的私人数据；共享城市地图不表示共享照片。用户有编程基础，具体技术由助手选择，兼顾学习与开发效率。

## 第一版边界

| 方面 | 已确定的方向 |
| --- | --- |
| 使用设备 | 电脑端 Web，Edge 为主要验证浏览器 |
| 网络与交付 | 默认联网；先本地开发完善，再部署网址并验证跨电脑访问 |
| 主要入口 | 中国地图，直接选地级市或同级城市单元；有照片才点亮城市范围，省界作浅色辅助 |
| 浏览结构 | 城市 → 年份影集框 → 照片；年份从新到旧，不按月份分组，可先建空影集 |
| 内容整理 | 影集内自由排序；编号可辅助导入，不要求重命名；支持跨城市、跨年份移动及单张文字 |
| 照片来源 | 手机导入电脑后整理在 U 盘或电脑中，由用户选择添加；系统保留独立原图副本 |
| 图片要求 | 保存原始字节，查看原图，第一版不另生成小预览图 |
| 预期规模 | 本人初期约 3000 张，常去城市单年份 300 多张；作为验证场景，不是数量上限 |
| 风格 | 暖色旅行手帐，地图与照片为主体，减少大段装饰文字 |

无年份照片仍能保留与回看；当前设计提供最后一个“未标年份”入口。重复照片由本人查看并决定保留或删除；删除方式由用户委托选择，采用 30 天回收站。这些具体规则及验收条件统一记录在需求和数据设计中。

## 核心使用场景

1. 记录：选择城市与年份，创建影集，添加原图，再按游玩顺序整理并写文字。
2. 回看：从地图或城市搜索进入某一年，查看照片与记录，返回时保留浏览位置。
3. 换电脑：上线后登录同一账号，继续访问已经保存的影集，无需重新导入。

## 第一版不做及暂缓项

用户已明确不提供公共照片浏览，暂不做 QQ 等第三方登录，也不要求离线使用。按现有范围暂缓手机专门适配、多人共编、社交分享、完整游记、路线规划、智能整理和手机相册自动同步。未提及的功能不自动纳入第一版。

## 怎样判断值得使用

- 能找到想回顾的城市和年份，按自己安排的顺序查看清晰的照片与文字。
- 保存后关闭并重新打开，照片、空影集、顺序和文字仍在。
- 不同账号的内容隔离，误删可在保留期内恢复，备份能还原原图与关系。
- 在目标规模下能正常浏览与整理；部署后跨电脑访问同一份资料。
