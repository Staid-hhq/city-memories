# 原图加载可行性探针

这是阶段 3 的一次性技术验证，不是正式应用或页面设计稿。仅使用 Node 内置模块与本机 Edge，不安装项目依赖。

在项目根目录的 PowerShell 中运行：

~~~powershell
& 'D:\SDK\Node\node.exe' .\validation\gallery-probe\run.mjs 'E:\赤湾烟波-深圳'
~~~

服务仅监听随机的本机回环端口，使用每次随机生成的路径令牌，只映射指定文件夹顶层 JPG 文件。源文件只读，测试前后核对 SHA-256；不复制图片、不生成预览图，不向第三方发送图片。Edge 使用独立配置目录并以无界面方式运行；结果返回或超时后关闭本次测试服务与进程。

400 条合成记录循环引用 23 张样本的原始文件内容，使用独立 URL 和 no-store 响应，每次只挂载当前页的 12 张。脚本遍历所有页，检查解码、首屏请求数量、末页记录、原图打开与返回、失败提示和恢复。分页仅为验证手段。

结果保存于 results 下的独立时间目录：

- result.json：实际浏览器环境、断言、计时、请求统计与原文件哈希。
- edge-gallery.png：Edge 渲染的测试页。
- dom.html：页面自测完成后的 DOM。
- edge-stderr.log：浏览器诊断信息。
- edge-profile：与用户日常 Edge 数据隔离的测试配置。

已完成的两次运行（2026-09-20T09-44-39-742Z、2026-09-20T09-46-53-974Z）的 edge-profile 目录已在收尾时清理，证据文件保留。以后再次运行会生成新的独立配置目录；results 已列入本目录的 .gitignore。

限制：重复样本不是 400 张不同真实照片；回环网络与无界面模式不是实际互联网或人工体验测试。3000 条数据仅构造元数据，不代表数据库、原图存储、账号隔离或持久排序已验证。不提供地图、注册登录或照片管理产品功能。
