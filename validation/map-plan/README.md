# T12 地图方案离线检查

运行目录为项目根目录：

```powershell
& 'D:\SDK\Node\node.exe' --test validation/map-plan/map-plan.test.mjs
```

使用 Node 自带的 test/vm，无需安装依赖。读取原型适配器代码，注入合成目录/几何、假时钟和 fetch 替身；**不联网、不读取 Key、不访问私人数据、不启动真实服务**。代码中的全零占位值只供虚拟 fetch 返回，不会发送任何网络请求。

当前 19 项覆盖分类、异常资料、严格边界匹配、查询复用、失败重试、多面/孔洞与原型排队下限。测试中的“34 省”和名称/坐标是编造的夹具，不是行政区划事实；51 秒是零网络延迟下模拟得到的调度下限，不是实测加载耗时。

完整来源、配额证据、缺项和 T13 验收方案见 [T12 核对报告](../../docs/t12-map-data-loading.md)。这些测试不能替代全国映射审核、使用条件或真实 Edge 地图检查。
