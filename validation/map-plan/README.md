# T12 地图方案检查

## 离线回归（默认验证，无外部调用）

运行目录为项目根目录：

```powershell
& 'D:\SDK\Node\node.exe' --test validation/map-plan/map-plan.test.mjs
```

使用 Node 自带的 test/vm，无需安装依赖。读取原型适配器代码，注入合成目录/几何、假时钟和 fetch 替身；**不联网、不读取 Key、不访问私人数据、不启动真实服务**。代码中的全零占位值只供虚拟 fetch 返回，不会发送任何网络请求。

当前 27 项覆盖分类、特殊县级遗漏、异常资料、严格边界匹配、查询复用、失败重试、多面/孔洞、在线报告门禁与原型排队下限。合成节点使用部分公开地名/代码，其层级、中心点和组合均为测试构造，不是全国数据集；51 秒是零网络延迟下模拟得到的调度下限，不是实测加载耗时。

## 可选在线核验（会产生真实服务调用）

需要已按锁文件准备的 `frontend/node_modules`（复用 Playwright 1.63.0）和本机 Microsoft Edge。读取已有 `validation/map-probe/.env.local` 中的 `TIANDITU_KEY`，或同名进程环境变量；不要把真实值放入命令、源码或提交。浏览器 Key 由独立浏览器正常访问官方 HTTPS，不做服务端代理，不连接用户已有浏览器配置/会话。

在项目根目录显式运行：

```powershell
& 'D:\SDK\Node\node.exe' validation/map-plan/live.mjs wmts
```

`wmts` 是默认模式：一个全国目录请求（不取几何）及五组固定视角的官方 `vec_w + cva_w`。只显示当前视口、每个视口最多 100 张底图/注记图片，不遍历地图或预取邻域；底图/注记按普通在线页面加载，不打包瓦片。包含初始视图，瓦片 DOM 数不是唯一请求数，真实消耗以控制台为准。

`national` 使用官方 JS SDK，查询一次目录并检查两个视角；`regions` 使用 SDK 检查四个区域、不查询目录。两者是故障对照，2026-10-04 均复现官方 `military.js` 的 `T.Tool.extend` 异常，预计整体失败；不把底图可见当作无异常通过。不需要为日常离线回归重复运行这些模式。

`--review` 可额外在终端列出公开候选名称/编码供人工核对，不输出完整响应、坐标或 Key。来源结构门禁检查省级覆盖、来源/类别计数、冲突/拒绝项、三条现有业务映射、补回的 11 个县/林区及特殊类别；**它不代表逐条独立行政认证**，也不按历史 380/391 数量强行通过。

服务仅绑定 127.0.0.1 随机端口与随机路径，限制 Host、Origin、方法和静态文件白名单；自动检查未限定路径 404、跨来源 403。独立无头 Edge 完成后关闭，服务器也关闭。真实 Key 只在服务/页面内存与正常官方网络请求中使用；报告脱敏，原始目录仅浏览器内存处理。

报告和视觉检查截图写入被忽略的 `results/<UTC时间>/`，不要强制提交，不包含私人照片。夹具不是正式地图组件，不支持产品鼠标交互；静态审图号仅记录 2026-10-04 官方 SDK 显示值，不能复制成永久生产配置。2026-10-04 WMTS 五组视图加载通过、页面异常为 0；加强后的结构门禁对该报告进行了离线复核，未为此增加真实请求。

完整来源、配额证据、运行目录和 T13 验收方案见 [T12 核对报告](../../docs/t12-map-data-loading.md)。这些检查不能替代正式城市表逐条门禁、产品全图与叠加交互验收或对外使用条件复核。
